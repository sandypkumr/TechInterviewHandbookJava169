A tree is an undirected graph in which any two vertices are connected by _exactly_ one path. In other words, any connected graph without simple cycles is a tree.

Given a tree of `n` nodes labelled from `0` to `n - 1`, and an array of `n - 1` `edges` where `edges[i] = [ai, bi]` indicates that there is an undirected edge between the two nodes `ai` and `bi` in the tree, you can choose any node of the tree as the root. When you select a node `x` as the root, the result tree has height `h`. Among all possible rooted trees, those with minimum height (i.e. `min(h)`)  are called **minimum height trees** (MHTs).

Return _a list of all **MHTs'** root labels_. You can return the answer in **any order**.

The **height** of a rooted tree is the number of edges on the longest downward path between the root and a leaf.

**Example 1:**

```
Input: n = 4, edges = [[1,0],[1,2],[1,3]]
Output: [1]
Explanation: As shown, the height of the tree is 1 when the root is the node with label 1 which is the only MHT.
```

**Example 2:**

```
Input: n = 6, edges = [[3,0],[3,1],[3,2],[3,4],[5,4]]
Output: [3,4]
```

**Constraints:**

- `1 <= n <= 2 * 10^4`

- `edges.length == n - 1`

- `0 <= ai, bi < n`

- `ai != bi`

- All the pairs `(ai, bi)` are distinct.

- The given input is **guaranteed** to be a tree and there will be **no repeated** edges.

## Java Solution

```java
package graph;

import java.util.ArrayList;
import java.util.HashSet;
import java.util.List;
import java.util.Set;

public class MinimumHeightTrees {
    public List<Integer> findMinHeightTrees(int n, int[][] edges) {
        List<Integer> result = new ArrayList<>();
        if (n == 0) return result;
        if (n == 1) {
            result.add(0);
            return result;
        }

        List<Set<Integer>> adj = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            adj.add(new HashSet<>());
        }
        for (int[] edge : edges) {
            adj.get(edge[0]).add(edge[1]);
            adj.get(edge[1]).add(edge[0]);
        }

        List<Integer> leaves = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            if (adj.get(i).size() == 1) {
                leaves.add(i);
            }
        }

        int remainingNodes = n;
        while (remainingNodes > 2) {
            remainingNodes -= leaves.size();
            List<Integer> newLeaves = new ArrayList<>();
            for (int leaf : leaves) {
                int neighbor = adj.get(leaf).iterator().next();
                adj.get(neighbor).remove(leaf);
                if (adj.get(neighbor).size() == 1) {
                    newLeaves.add(neighbor);
                }
            }
            leaves = newLeaves;
        }

        return leaves;
    }
}
```

## Explanation

### Problem Analysis
The task is to find all roots that make a tree’s height as small as possible. This is a common interview problem because it tests whether you can stop thinking in terms of “try every root” and instead use tree structure to identify the center efficiently.

### Approach
A brute-force solution would root the tree at every node and compute its height each time, which is too slow. This code uses the fact that the root of a minimum-height tree must lie at the center of the tree, so it repeatedly removes the current leaves until only one or two center nodes remain.

You can think of it as peeling the tree from the outside inward. The last layer left is exactly the set of valid MHT roots.

### Pattern Used
BFS / Topological leaf trimming on an undirected tree

### Key Insight
If you remove all leaves level by level, the final one or two nodes left are the tree centers, and those centers are the only roots that minimize height.

### Code Walkthrough
In `findMinHeightTrees(int n, int[][] edges)`:
- `result` is created first for the return value.
- `if (n == 0) return result;` handles an empty graph input defensively.
- `if (n == 1)` returns `[0]` because a single node is already the only possible root.

To build the graph:
- `List<Set<Integer>> adj = new ArrayList<>();` creates an adjacency list.
- Each node gets a `HashSet<>` so neighbors can be removed efficiently later.
- The `for (int[] edge : edges)` loop adds the undirected connection both ways.

To find the initial leaves:
- `List<Integer> leaves = new ArrayList<>();`
- The loop over `i` checks `adj.get(i).size() == 1`.
- Any node with exactly one neighbor is a current leaf and gets added to `leaves`.

To peel the tree:
- `remainingNodes = n` tracks how many nodes are still active.
- `while (remainingNodes > 2)` keeps trimming until only the center layer remains.
- `remainingNodes -= leaves.size();` removes the whole current layer logically.
- `newLeaves` stores the next layer that becomes leaves after trimming.

Inside the leaf-removal loop:
- For each `leaf`, `adj.get(leaf).iterator().next()` gets its only remaining neighbor.
- `adj.get(neighbor).remove(leaf)` cuts the edge from that neighbor back to the leaf.
- If that neighbor now has degree 1, it becomes a new leaf and is added to `newLeaves`.
- After processing the whole layer, `leaves = newLeaves` moves to the next BFS level.

When the loop ends:
- The remaining `leaves` list contains one or two centers.
- The method returns `leaves` directly.

### Example Walkthrough
Use Example 2:
- `n = 6`
- `edges = [[3,0],[3,1],[3,2],[3,4],[5,4]]`

After building `adj`:
- Node `0` connects to `3`
- Node `1` connects to `3`
- Node `2` connects to `3`
- Node `4` connects to `3` and `5`
- Node `5` connects to `4`

Initial leaves are:
- `leaves = [0, 1, 2, 5]`
- `remainingNodes = 6`

First trimming round:
- Remove 4 leaves, so `remainingNodes = 2`.
- Removing `0`, `1`, and `2` reduces node `3`’s degree step by step.
- Removing `5` reduces node `4`’s degree to 1.
- Now `newLeaves = [3, 4]`.

The loop stops because `remainingNodes` is no longer greater than 2. The answer is `[3, 4]`, which matches the example.

### Key Variables Explained
- `adj`: adjacency list where each `Set<Integer>` holds the current neighbors of a node.
- `leaves`: nodes with degree 1 in the current outer layer.
- `newLeaves`: nodes that become leaves after removing the current layer.
- `remainingNodes`: number of nodes not yet peeled away.
- `neighbor`: the only connected node left for a current leaf.

### Why This Works
In a tree, the farthest nodes from any center are always leaves. Removing all leaves shortens every longest path by one layer from both ends, but it does not change the center of the tree.

Repeating that process eventually leaves either one node or two adjacent nodes. Those are exactly the centers of the original tree, and choosing any of them as root gives the minimum possible height.

### Trick Used
Repeatedly trimming degree-1 nodes instead of computing tree height from every possible root.

### Edge Cases Handled
- `n == 0`: returns an empty list immediately.
- `n == 1`: returns `[0]` without building unnecessary structure.
- One-center vs two-center trees: the loop stops at `remainingNodes <= 2`, so both cases are returned correctly.
- Sparse leaf updates: using `Set` lets the code remove a leaf from its neighbor cleanly.

### Complexity Analysis
- Time Complexity: `O(n)` because building `adj` processes `n - 1` edges once, and each edge is effectively removed once during leaf trimming.
- Space Complexity: `O(n)` for the adjacency sets and the leaf lists.
