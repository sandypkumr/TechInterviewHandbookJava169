Given an `m x n` `board` of characters and a list of strings `words`, return _all words on the board_.

Each word must be constructed from letters of sequentially adjacent cells, where **adjacent cells** are horizontally or vertically neighboring. The same letter cell may not be used more than once in a word.

**Example 1:**

```
Input: board = [["o","a","a","n"],["e","t","a","e"],["i","h","k","r"],["i","f","l","v"]], words = ["oath","pea","eat","rain"]
Output: ["eat","oath"]
```

**Example 2:**

```
Input: board = [["a","b"],["c","d"]], words = ["abcb"]
Output: []
```

**Constraints:**

- `m == board.length`

- `n == board[i].length`

- `1 <= m, n <= 12`

- `board[i][j]` is a lowercase English letter.

- `1 <= words.length <= 3 * 10^4`

- `1 <= words[i].length <= 10`

- `words[i]` consists of lowercase English letters.

- All the strings of `words` are unique.

**Patterns:** `dfs`, `trie`

## Java Solution

```java
package graph;

import java.util.*;

public class WordSearch2 {
    class TrieNode {
        Map<Character, TrieNode> children = new HashMap<>();
        String word = null;
    }

    private char[][] board;
    private Set<String> result = new HashSet<>();
    private int m, n;

    public List<String> findWords(char[][] board, String[] words) {
        this.board = board;
        m = board.length;
        n = board[0].length;

        TrieNode root = new TrieNode();

        for (String word : words) {
            TrieNode node = root;
            for (char c : word.toCharArray()) {
                node = node.children.computeIfAbsent(c, k -> new TrieNode());
            }
            node.word = word;
        }

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (root.children.containsKey(board[i][j])) {
                    dfs(i, j, root);
                }
            }
        }

        return new ArrayList<>(result);
    }

    private void dfs(int i, int j, TrieNode node) {
        char c = board[i][j];
        TrieNode curr = node.children.get(c);
        if (curr == null) return;
        if (curr.word != null) {
            result.add(curr.word);
        }
        board[i][j] = '#';

        int[][] dirs = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
        for (int[] dir : dirs) {
            int newX = i + dir[0];
            int newY = j + dir[1];
            if (newX >= 0 && newX < m && newY >= 0 && newY < n && board[newX][newY] != '#') {
                dfs(newX, newY, curr);
            }
        }
        board[i][j] = c;
    }
}
```

## Explanation

### Problem Analysis

We must return every word from `words` that can be formed by walking adjacent cells on the board without reusing a cell in the same path. Since there can be up to `3 * 10^4` candidate words, checking each word independently against the board would repeat a lot of prefix work.

This is a strong interview problem because it combines two ideas: graph-style DFS on the board and trie-based prefix pruning for many string queries at once.

### Approach

The solution first inserts all words into a trie, then starts DFS from each board cell whose character appears as a first trie edge. During DFS, the current trie node tells us whether the current board path is still a valid prefix of at least one word.

That pruning is the main reason this beats brute force. Without the trie, the search would explore many board paths that can never lead to any target word.

### Pattern Used

**Trie + DFS Backtracking**

### Key Insight

If the current board path is not a prefix in the trie, we can stop immediately instead of exploring the rest of that path.

### Code Walkthrough

`TrieNode` stores:

- `Map<Character, TrieNode> children` for outgoing letters
- `String word = null` to mark the end of a complete word

The class also keeps:

- `private char[][] board;`
- `private Set<String> result = new HashSet<>();`
- `private int m, n;`

Inside `findWords(char[][] board, String[] words)`:

- The input board is saved into `this.board`
- `m` and `n` are initialized from the board dimensions
- `TrieNode root = new TrieNode();` creates the trie root

The first `for (String word : words)` loop builds the trie:

- Start from `root`
- For each `char c`, move with `node.children.computeIfAbsent(c, k -> new TrieNode())`
- After all letters are inserted, set `node.word = word`

Next, the double loop scans every board cell:

- `if (root.children.containsKey(board[i][j])) dfs(i, j, root);`

That check avoids starting DFS from letters that cannot begin any word.

Inside `dfs(int i, int j, TrieNode node)`:

- `char c = board[i][j];`
- `TrieNode curr = node.children.get(c);`
- If `curr == null`, this path is not a valid prefix, so return

If `curr.word != null`, a full word has been matched, so `result.add(curr.word);`

Then the current board cell is marked as used with `board[i][j] = '#';`

The code explores the four directions from `dirs`. For each valid neighbor that is not already `'#'`, it calls `dfs(newX, newY, curr)`.

Finally, `board[i][j] = c;` restores the letter so other searches can reuse that cell later.

The method returns `new ArrayList<>(result);`

### Example Walkthrough

Use **Example 1**:

- `board = [["o","a","a","n"],["e","t","a","e"],["i","h","k","r"],["i","f","l","v"]]`
- `words = ["oath","pea","eat","rain"]`

Trie construction stores all four words, with shared prefixes merged when possible.

Board scan:

- Starting at `(0,0) = 'o'`, the trie has an `'o'` child, so DFS begins
- Path `o -> a -> t -> h` matches `"oath"`
- At the trie node for `'h'`, `curr.word` is `"oath"`, so it is added to `result`

Later, another useful start is `(1,3) = 'e'`:

- DFS can follow `e -> a -> t`
- That reaches the trie node whose `word` is `"eat"`
- `"eat"` is added to `result`

`"pea"` is never formed from adjacent cells, and `"rain"` also cannot be completed on this board.

So the final result contains `["eat", "oath"]` in any order, which matches the example output.

### Key Variables Explained

- `root`: trie root containing all words
- `children`: outgoing trie edges for each character
- `word`: non-null only at trie nodes that complete a dictionary word
- `board`: stored as a field so `dfs` can access it directly
- `result`: `HashSet` collecting found words without duplicates
- `m`, `n`: board dimensions
- `curr`: trie node for the current board character
- `dirs`: the four neighboring moves inside DFS

### Why This Works

Each DFS path represents one candidate string formed from adjacent board cells, and the trie node passed into recursion represents exactly the prefix matched so far. Because recursion only continues through `curr`, every explored path is consistent with at least one dictionary prefix.

Marking a cell as `'#'` prevents illegal reuse within the same word path, and restoring it afterward enables other independent searches. Using a `Set<String>` for `result` ensures repeated discoveries of the same word do not create duplicates in the answer.

### Trick Used

The search is pruned twice: once before DFS with `root.children.containsKey(board[i][j])`, and again inside DFS with `if (curr == null) return;`.

### Edge Cases Handled

- **Shared prefixes among words:** naturally handled by the trie structure
- **The same word found through multiple paths:** deduplicated by `result`
- **Cell reuse not allowed:** enforced by temporarily writing `'#'`
- **Dead paths:** stopped immediately when the trie has no matching child

### Complexity Analysis

- **Time Complexity: `O(W + m * n * 4 * 3^(L - 1))` in the worst case** — building the trie costs `O(W)`, where `W` is the total number of characters across all words. The DFS part can, in the worst case, branch up to 4 ways initially and up to 3 ways afterward for paths of maximum length `L`.
- **Space Complexity: `O(W + L + R)`** — the trie stores `O(W)` characters, recursion depth is at most `L`, and `result` stores the found words. This is more accurate for this code than `O(L)` alone because the trie dominates auxiliary space.
