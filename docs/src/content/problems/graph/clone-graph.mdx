Given a reference of a node in a **connected** undirected graph.

Return a **deep copy** (clone) of the graph.

Each node in the graph contains a value (`int`) and a list (`List[Node]`) of its neighbors.

```
class Node {
    public int val;
    public List neighbors;
}
```

**Test case format:**

For simplicity, each node's value is the same as the node's index (1-indexed). For example, the first node with `val == 1`, the second node with `val == 2`, and so on. The graph is represented in the test case using an adjacency list.

**An adjacency list** is a collection of unordered **lists** used to represent a finite graph. Each list describes the set of neighbors of a node in the graph.

The given node will always be the first node with `val = 1`. You must return the **copy of the given node** as a reference to the cloned graph.

**Example 1:**

```
Input: adjList = [[2,4],[1,3],[2,4],[1,3]]
Output: [[2,4],[1,3],[2,4],[1,3]]
Explanation: There are 4 nodes in the graph.
1st node (val = 1)'s neighbors are 2nd node (val = 2) and 4th node (val = 4).
2nd node (val = 2)'s neighbors are 1st node (val = 1) and 3rd node (val = 3).
3rd node (val = 3)'s neighbors are 2nd node (val = 2) and 4th node (val = 4).
4th node (val = 4)'s neighbors are 1st node (val = 1) and 3rd node (val = 3).
```

**Example 2:**

```
Input: adjList = [[]]
Output: [[]]
Explanation: Note that the input contains one empty list. The graph consists of only one node with val = 1 and it does not have any neighbors.
```

**Example 3:**

```
Input: adjList = []
Output: []
Explanation: This an empty graph, it does not have any nodes.
```

**Constraints:**

- The number of nodes in the graph is in the range `[0, 100]`.

- `1 <= Node.val <= 100`

- `Node.val` is unique for each node.

- There are no repeated edges and no self-loops in the graph.

- The Graph is connected and all nodes can be visited starting from the given node.

## Java Solution

```java
package graph;

import java.util.HashMap;
import java.util.Map;

public class CloneGraph {

    public Node cloneGraph(Node node) {
        if (node == null) return null;

        Map<Node, Node> map = new HashMap<>();
        return clone(node, map);
    }

    private Node clone(Node node, Map<Node, Node> map) {
        if (map.containsKey(node)) return map.get(node);

        Node newNode = new Node(node.val);
        map.put(node, newNode);

        for (Node neighbor : node.neighbors) {
            newNode.neighbors.add(clone(neighbor, map));
        }

        return newNode;
    }
}
```

## Explanation

### Problem Analysis

This problem asks for a deep copy of an undirected graph, not just a copy of one node. That means every original node must get its own new `Node` object, and every neighbor relationship must be recreated using cloned nodes rather than original references.

It is a classic interview problem because graphs may contain cycles, so a naive recursive copy can loop forever or create duplicate copies of the same node.

### Approach

The solution performs a DFS starting from the given node and uses a hash map to remember which original nodes have already been cloned.

In plain English:
- When we first see a node, we create its clone immediately.
- We store the mapping from original node to cloned node in `map`.
- Then we recursively clone each neighbor and attach those cloned neighbors to the new node.

This is better than brute force traversal without memoization because graphs can revisit the same node through multiple paths.

### Pattern Used

Depth-First Search (DFS) with a Hash Map for memoization.

### Key Insight

The crucial idea is to put a node into `map` before cloning its neighbors, so cycles and shared neighbors reuse the same clone instead of recursing forever.

### Code Walkthrough

The public method `cloneGraph(Node node)` handles the entry point.
- `if (node == null) return null;` handles the empty graph case.
- `Map<Node, Node> map = new HashMap<>();` creates the memo table.
- `return clone(node, map);` delegates the real work to the recursive helper.

The helper `clone(Node node, Map<Node, Node> map)` does the graph traversal.
- `if (map.containsKey(node)) return map.get(node);` means this original node was already cloned earlier, so the method reuses that existing clone.

If the node has not been cloned yet:
- `Node newNode = new Node(node.val);` creates the deep-copy node with the same value.
- `map.put(node, newNode);` stores the mapping immediately.

Then the loop `for (Node neighbor : node.neighbors)` rebuilds the adjacency list.
- For each original `neighbor`, the code calls `clone(neighbor, map)`.
- That recursive call returns the cloned version of the neighbor.
- `newNode.neighbors.add(...)` connects the cloned current node to the cloned neighbor.

After all neighbors are processed, the helper returns `newNode`.

### Example Walkthrough

Use Example 1: `adjList = [[2,4],[1,3],[2,4],[1,3]]`.

Start at node `1`:
- `cloneGraph(node1)` creates `map` and calls `clone(node1, map)`.
- `node1` is not in `map`, so create `newNode1` and store `map[node1] = newNode1`.

Process neighbors of node `1`:
- First neighbor is node `2`.
- `clone(node2, map)` creates `newNode2`, stores it, then processes node `2`'s neighbors.

Inside node `2`:
- Neighbor `1` is already in `map`, so the code reuses `newNode1`.
- Neighbor `3` is new, so `clone(node3, map)` creates `newNode3`.

Inside node `3`:
- Neighbor `2` is already cloned, so reuse `newNode2`.
- Neighbor `4` is new, so `clone(node4, map)` creates `newNode4`.

Inside node `4`:
- Neighbor `1` reuses `newNode1`.
- Neighbor `3` reuses `newNode3`.

As recursion unwinds:
- `newNode4` is attached to `newNode3`
- `newNode3` is attached to `newNode2`
- `newNode2` and `newNode4` are attached to `newNode1`

The returned graph has the same connections as the original, but every node object is newly created.

### Key Variables Explained

- `node`: the current original graph node being cloned.
- `map`: stores `original node -> cloned node` so each original node is copied exactly once.
- `newNode`: the clone created for the current `node`.
- `neighbor`: one adjacent original node from `node.neighbors`.
- `clone(...)`: recursive helper that returns the clone for any original node.

### Why This Works

The method maintains a simple invariant: whenever a node appears in `map`, its clone already exists and can be safely reused.

That guarantees correctness because:
- Every original node gets exactly one clone object.
- Every original edge is recreated when the code iterates through `node.neighbors`.
- Cycles do not cause infinite recursion because revisiting a node hits `map.containsKey(node)` and returns immediately.

So the final graph is both structurally identical and fully detached from the original graph.

### Trick Used

The trick is the early `map.put(node, newNode)` before recursing into neighbors, which is what makes cyclic graphs safe to clone.

### Edge Cases Handled

- Empty graph: `node == null` returns `null` immediately.
- Single node with no neighbors: the loop over `node.neighbors` simply adds nothing, producing a one-node clone.
- Cycles and shared neighbors: `map.containsKey(node)` prevents duplicate cloning and infinite recursion.

### Complexity Analysis

- Time Complexity: `O(V + E)`.
  - Each node is cloned once.
  - Each neighbor list is traversed once, so across the whole graph every edge is processed during DFS.
- Space Complexity: `O(V)`.
  - The `map` can store every node.
  - The recursion stack can also grow up to `O(V)` in the worst case.
