You are given a 2D grid where:

Each cell in the grid can be one of the following:
'*': Your starting position. There is exactly one '*' in the grid.
'#': A food cell. There may be multiple food cells.
'O': An open cell you can walk through.
'X': A blocked cell you cannot walk through.
You need to find the shortest path from your starting position ('*') to any food cell ('#') in the grid. You can move
 up, down, left, or right. Return the number of steps in the shortest path, or -1 if no path exists.


**Example 1:**

**Input: grid =   [["X","X","X","X","X","X"],**
                 ["X","*","O","O","O","X"],
                 ["X","O","O","#","O","X"],
                 ["X","X","X","X","X","X"]]

**Output: 3**
Explanation: It takes 3 steps to reach the food.

**Patterns:** `sliding-window`, `bfs`

## Java Solution

```java
package graph;

import java.util.LinkedList;
import java.util.Queue;

/**
 * You are given a 2D grid where:
 *
 * Each cell in the grid can be one of the following:
 * '*': Your starting position. There is exactly one '*' in the grid.
 * '#': A food cell. There may be multiple food cells.
 * 'O': An open cell you can walk through.
 * 'X': A blocked cell you cannot walk through.
 * You need to find the shortest path from your starting position ('*') to any food cell ('#') in the grid. You can move
 *  up, down, left, or right. Return the number of steps in the shortest path, or -1 if no path exists.
 *
 * Example 1:
 * Input: grid =   [["X","X","X","X","X","X"],
 *                  ["X","*","O","O","O","X"],
 *                  ["X","O","O","#","O","X"],
 *                  ["X","X","X","X","X","X"]]
 * Output: 3
 * Explanation: It takes 3 steps to reach the food.
 */
public class ShortestPathToGetFood {
    public int getFood(char[][] grid) {
        int rows = grid.length;
        int cols = grid[0].length;
        Queue<int[]> queue = new LinkedList<>();
        boolean[][] visited = new boolean[rows][cols];

        for (int r = 0; r < rows; r++) {
            for (int c = 0; c < cols; c++) {
                if (grid[r][c] == '*') {
                    queue.offer(new int[]{r, c, 0});
                    visited[r][c] = true;
                }
            }
        }

        int[][] directions = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
        while (!queue.isEmpty()) {
            int[] cell = queue.poll();
            int r = cell[0], c = cell[1], dist = cell[2];

            if (grid[r][c] == '#') {
                return dist;
            }

            for (int[] dir : directions) {
                int nr = r + dir[0];
                int nc = c + dir[1];
                if (nr >= 0 && nr < rows && nc >= 0 && nc < cols && !visited[nr][nc] && (grid[nr][nc] != 'X')) {
                    visited[nr][nc] = true;
                    queue.offer(new int[]{nr, nc, dist + 1});
                }
            }
        }

        return -1;
    }
}
```

## Explanation

### Problem Analysis

The task is to find the minimum number of moves from the single starting cell `'*'` to any food cell `'#'` in a grid with walls `'X'` and open cells `'O'`. Because each move has equal cost and movement is only in four directions, this is a shortest-path problem on an unweighted grid graph.

This is a common interview question because it checks whether you can model a matrix as a graph and immediately choose BFS for shortest distance.

### Approach

The code first finds the start cell, pushes it into a queue, and then performs BFS outward. Each queued entry stores three values: row, column, and current distance from the start.

This is preferred over DFS or brute-force path enumeration because BFS guarantees that the first time we reach any `'#'`, we have found the shortest route. The `visited` matrix prevents revisiting cells and keeps the search linear.

### Pattern Used

**BFS for shortest path in an unweighted grid**

### Key Insight

Once a cell is dequeued in BFS, its stored `dist` is the minimum number of steps needed to reach it, so the first dequeued food cell gives the answer immediately.

### Code Walkthrough

The method begins by computing `rows` and `cols`, then creating:

- `Queue<int[]> queue` for BFS
- `boolean[][] visited` to avoid processing the same cell twice

The nested `for` loops scan the grid to find `'*'`.

- When `grid[r][c] == '*'`, the code enqueues `new int[]{r, c, 0}`
- It also marks `visited[r][c] = true`

`directions` stores the four legal moves.

The main BFS loop is `while (!queue.isEmpty())`.

- `int[] cell = queue.poll();`
- `int r = cell[0], c = cell[1], dist = cell[2];`

The first check inside the loop is:

- `if (grid[r][c] == '#') return dist;`

That works because BFS explores cells in increasing distance order.

Then the code iterates over each `dir` in `directions`:

- `nr` and `nc` are the next coordinates
- The `if` condition checks bounds, makes sure the cell was not visited, and rejects walls using `grid[nr][nc] != 'X'`
- Valid neighbors are marked visited immediately and enqueued with distance `dist + 1`

If the queue empties without reaching food, the method returns `-1`.

### Example Walkthrough

Use the given example:

`grid = [["X","X","X","X","X","X"],["X","*","O","O","O","X"],["X","O","O","#","O","X"],["X","X","X","X","X","X"]]`

Start scan:

- `queue = [(1,1,0)]`
- `visited[1][1] = true`

Process `(1,1,0)`:

- Not food
- Enqueue `(2,1,1)` and `(1,2,1)`

Process distance `1` cells:

- From `(2,1,1)`, enqueue `(2,2,2)`
- From `(1,2,1)`, enqueue `(1,3,2)`

Process distance `2` cells:

- From `(2,2,2)`, one neighbor is `(2,3)` which is `'#'`, so enqueue `(2,3,3)`
- `(1,3,2)` may add other open cells, but BFS still keeps distance order

Next dequeue is `(2,3,3)`:

- `grid[r][c] == '#'`, so the code returns `3`

That matches the expected output.

### Key Variables Explained

- `queue`: BFS worklist storing `{row, col, distance}`
- `visited`: prevents reprocessing cells and infinite revisits
- `directions`: the four movement offsets
- `r`, `c`: current cell coordinates
- `dist`: shortest distance from `'*'` to the current cell
- `nr`, `nc`: coordinates of a neighboring cell being tested

### Why This Works

BFS explores the grid in concentric distance layers from the start. Because every move costs exactly one step, there is no cheaper way to reach a cell after it has already been dequeued once.

Marking `visited[nr][nc] = true` at enqueue time is important: it guarantees each reachable cell enters the queue only once, so the first recorded distance for that cell remains its shortest distance.

### Trick Used

The distance is stored directly inside each queued array as `{r, c, dist}`, which removes the need for a separate level counter.

### Edge Cases Handled

- **Food unreachable:** if BFS finishes without seeing `'#'`, the method returns `-1`
- **Blocked cells:** the condition `grid[nr][nc] != 'X'` prevents entering walls
- **Revisits:** `!visited[nr][nc]` avoids duplicate work
- **Food adjacent to start:** it will be enqueued with distance `1` and returned immediately when polled

### Complexity Analysis

- **Time Complexity: `O(rows * cols)`** — the initial scan touches every cell once, and BFS visits each reachable cell at most once.
- **Space Complexity: `O(rows * cols)`** — the `visited` matrix is `rows x cols`, and the queue can also grow to that size in the worst case.
