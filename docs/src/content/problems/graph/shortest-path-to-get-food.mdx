You are given a 2D grid where:

Each cell in the grid can be one of the following:
'*': Your starting position. There is exactly one '*' in the grid.
'#': A food cell. There may be multiple food cells.
'O': An open cell you can walk through.
'X': A blocked cell you cannot walk through.
You need to find the shortest path from your starting position ('*') to any food cell ('#') in the grid. You can move
 up, down, left, or right. Return the number of steps in the shortest path, or -1 if no path exists.


**Example 1:**

**Input: grid =   [["X","X","X","X","X","X"],**
                 ["X","*","O","O","O","X"],
                 ["X","O","O","#","O","X"],
                 ["X","X","X","X","X","X"]]

**Output: 3**
Explanation: It takes 3 steps to reach the food.

**Patterns:** `sliding-window`, `bfs`

## Java Solution

```java
package graph;

import java.util.LinkedList;
import java.util.Queue;

/**
 * You are given a 2D grid where:
 *
 * Each cell in the grid can be one of the following:
 * '*': Your starting position. There is exactly one '*' in the grid.
 * '#': A food cell. There may be multiple food cells.
 * 'O': An open cell you can walk through.
 * 'X': A blocked cell you cannot walk through.
 * You need to find the shortest path from your starting position ('*') to any food cell ('#') in the grid. You can move
 *  up, down, left, or right. Return the number of steps in the shortest path, or -1 if no path exists.
 *
 * Example 1:
 * Input: grid =   [["X","X","X","X","X","X"],
 *                  ["X","*","O","O","O","X"],
 *                  ["X","O","O","#","O","X"],
 *                  ["X","X","X","X","X","X"]]
 * Output: 3
 * Explanation: It takes 3 steps to reach the food.
 */
public class ShortestPathToGetFood {
    public int getFood(char[][] grid) {
        int rows = grid.length;
        int cols = grid[0].length;
        Queue<int[]> queue = new LinkedList<>();
        boolean[][] visited = new boolean[rows][cols];

        for (int r = 0; r < rows; r++) {
            for (int c = 0; c < cols; c++) {
                if (grid[r][c] == '*') {
                    queue.offer(new int[]{r, c, 0});
                    visited[r][c] = true;
                }
            }
        }

        int[][] directions = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
        while (!queue.isEmpty()) {
            int[] cell = queue.poll();
            int r = cell[0], c = cell[1], dist = cell[2];

            if (grid[r][c] == '#') {
                return dist;
            }

            for (int[] dir : directions) {
                int nr = r + dir[0];
                int nc = c + dir[1];
                if (nr >= 0 && nr < rows && nc >= 0 && nc < cols && !visited[nr][nc] && (grid[nr][nc] != 'X')) {
                    visited[nr][nc] = true;
                    queue.offer(new int[]{nr, nc, dist + 1});
                }
            }
        }

        return -1;
    }
}
```

## Explanation

### Approach

**Shortest Path to Get Food** requires visiting nodes in order of their distance from the source — exactly what Breadth-First Search (BFS) guarantees. By processing nodes level by level via a queue (FIFO), BFS finds the shortest path in an unweighted graph and naturally handles all reachability questions.

Think of it as ripples spreading outward from a stone dropped in water. All nodes at distance 1 are visited before any node at distance 2, and so on. This property makes BFS the right tool whenever "minimum steps" or "level order" is part of the problem.

### Code Walkthrough

The solution is implemented in `getFood(char[][] grid)`:

1. Add the source node(s) to a queue and mark them visited.
2. While the queue is non-empty, poll the front node.
3. Process the current node (update answer, record level, etc.).
4. Enqueue all unvisited neighbours and mark them visited immediately to avoid re-processing.
5. The first time you reach the target, you have the shortest path.

### Complexity Analysis

- **Time Complexity: `O(m·n)`** — every cell of the m × n grid is visited at most once.
- **Space Complexity: `O(m·n)`** — a visited/DP matrix of the same dimensions as the input grid is maintained.
