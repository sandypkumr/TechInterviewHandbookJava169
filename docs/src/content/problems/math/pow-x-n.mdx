Implement pow(x, n), which calculates `x` raised to the power `n` (i.e., `x^n`).

**Example 1:**

```
Input: x = 2.00000, n = 10
Output: 1024.00000
```

**Example 2:**

```
Input: x = 2.10000, n = 3
Output: 9.26100
```

**Example 3:**

```
Input: x = 2.00000, n = -2
Output: 0.25000
Explanation: 2-2 = 1/22 = 1/4 = 0.25
```

**Constraints:**

- `-100.0  0`.

- `-10^4 <= x^n <= 10^4`

## Java Solution

```java
package math;

public class PowOfXAndN {
    public double myPow(double x, int n) {
        long N = n;
        if (N < 0) {
            x = 1 / x;
            N = -N;
        }
        double result = 1.0;
        while (N > 0) {
            if ((N % 2) == 1) {
                result *= x;
            }
            x *= x;
            N /= 2;
        }
        return result;
    }
}
```

## Explanation

### Approach

**Pow(x, n)** follows the classic divide-and-conquer pattern: split the problem into smaller independent sub-problems, solve each recursively, then combine the results. This typically yields O(n log n) time because each level of recursion does O(n) work and there are O(log n) levels.

Merge Sort is the canonical example: split the array in half, sort each half independently, then merge the two sorted halves in linear time. The "combine" step is where the real work happens.

### Code Walkthrough

The solution is implemented in `myPow(double x, int n)`:

1. Define the base case (array of size 0 or 1 is already solved).
2. Split the input roughly in half (or by another natural partition).
3. Recursively solve each half.
4. Merge or combine the two results to produce the answer for the full input.

### Complexity Analysis

- **Time Complexity: `O(log n)`** — the search space is halved at each step (binary search).
- **Space Complexity: `O(log n)`** — the recursion call stack grows to O(log n) depth.
