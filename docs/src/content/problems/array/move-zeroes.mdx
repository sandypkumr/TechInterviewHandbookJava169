Given an integer array `nums`, move all `0`'s to the end of it while maintaining the relative order of the non-zero elements.

**Note** that you must do this in-place without making a copy of the array.

**Example 1:**

```
Input: nums = [0,1,0,3,12]
Output: [1,3,12,0,0]
```
**Example 2:**

```
Input: nums = [0]
Output: [0]
```

**Constraints:**

- `1 <= nums.length <= 10^4`

- `-2^31 <= nums[i] <= 2^31 - 1`

**Follow up:** Could you minimize the total number of operations done?

## Java Solution

```java
package array;

public class MoveZeroes {
    public void moveZeroes(int[] nums) {
        int zeroIndex = 0;
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] != 0) {
                int temp = nums[zeroIndex];
                nums[zeroIndex++] = nums[i];
                nums[i] = temp;
            }
        }
    }
}
```

## Explanation

### Approach

**Move Zeroes** exploits sorted order (or a structural property) to let two pointers converge from opposite ends of the array, eliminating the need for a nested loop. When the current pair doesn't satisfy the condition, we know exactly which pointer to advance — so each element is visited at most once, giving O(n) time.

Imagine squeezing a tube of toothpaste from both ends simultaneously — instead of trying every possible pair (both ends → O(n²)), you make an informed decision at each step about which end to squeeze next.

### Code Walkthrough

The solution is implemented in `moveZeroes(int[] nums)`:

1. Sort the array if it isn't already (or confirm the existing order guarantees correctness).
2. Place one pointer at the start (left = 0) and one at the end (right = n - 1).
3. Compute the result for the current pair.
4. If the result is too small, advance left to increase it; if too large, move right backward.
5. Stop when the pointers meet or cross.

### Complexity Analysis

- **Time Complexity: `O(n)`** — the two pointers together traverse the array at most once — every element is visited at most twice.
- **Space Complexity: `O(1)`** — only a fixed number of extra variables are used; no data structures that scale with input.
