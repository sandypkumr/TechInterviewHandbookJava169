Given an integer array `nums`, return `true` if any value appears **at least twice** in the array, and return `false` if every element is distinct.

**Example 1:**

**Input:** nums = [1,2,3,1]

**Output:** true

**Explanation:**

The element 1 occurs at the indices 0 and 3.

**Example 2:**

**Input:** nums = [1,2,3,4]

**Output:** false

**Explanation:**

All elements are distinct.

**Example 3:**

**Input:** nums = [1,1,1,3,3,4,3,2,4,2]

**Output:** true

**Constraints:**

- `1 <= nums.length <= 10^5`

- `-10^9 <= nums[i] <= 10^9`

## Java Solution

```java
package array;

import java.util.HashSet;
import java.util.Set;

public class ContainsDuplicate {
    public boolean containsDuplicate(int[] nums) {
        Set<Integer> set = new HashSet<>();
        for (int num : nums) {
            if (!set.add(num)) {
                return true;
            }
        }
        return false;
    }
}
```

## Explanation

### Problem Analysis
This problem asks whether any value appears more than once in the array. The goal is a boolean answer, so the algorithm can stop as soon as it proves a duplicate exists.

This is a very common interview warm-up because it checks whether you know when to trade extra memory for faster lookups.

### Approach
The code scans the array once and stores previously seen numbers in a `HashSet`. For each `num`, it tries to insert it into the set.

That gives a direct improvement over brute force:
- brute force compares each number with many later numbers in `O(n^2)` time
- the set lets the code detect repeats in constant-time average lookup/insert work

### Pattern Used
Hashing

### Key Insight
If a number has already been seen, inserting it into a `HashSet` fails immediately, so one pass is enough to detect any duplicate.

### Code Walkthrough
The method begins with:
- `Set<Integer> set = new HashSet<>();`

This set holds all distinct values encountered so far.

Then the loop `for (int num : nums)` processes each element in order.

Inside the loop:
- `set.add(num)` tries to insert the current value
- `HashSet.add(...)` returns `false` if the value is already present
- the code uses `if (!set.add(num)) { return true; }`

That means the method exits as soon as it finds the first repeated number.

If the loop finishes without triggering the early return, then every value was unique, so the method returns `false`.

### Example Walkthrough
Use Example 1: `nums = [1,2,3,1]`.

Start with `set = {}`.

Read `1`:
- `set.add(1)` succeeds
- `set = {1}`

Read `2`:
- `set.add(2)` succeeds
- `set = {1,2}`

Read `3`:
- `set.add(3)` succeeds
- `set = {1,2,3}`

Read the last `1`:
- `set.add(1)` returns `false` because `1` is already in the set
- the method immediately returns `true`

That matches the expected output.

### Key Variables Explained
- `set`: stores every distinct number seen so far
- `num`: current array element being checked
- return value of `set.add(num)`: tells the code whether `num` was new or already present

### Why This Works
The invariant is simple: before each iteration, `set` contains exactly the numbers already processed. So when the next `num` arrives:
- if `set.add(num)` succeeds, this is the first time `num` has appeared
- if it fails, `num` has appeared before, which is exactly the definition of a duplicate

Because the loop checks every element until a duplicate is found or the array ends, the returned boolean is correct.

### Trick Used
Using the boolean return value of `set.add(num)` to combine lookup and insertion in one operation

### Edge Cases Handled
- Duplicate appears early: the method returns immediately without scanning the rest
- All numbers distinct, like Example 2: the loop finishes and returns `false`
- Many repeated values, like Example 3: the first repeated insertion triggers `true`
- Single-element input: one insertion succeeds, then the method returns `false`

### Complexity Analysis
- **Time Complexity: `O(n)` average** — the loop visits each element once, and each `HashSet` insertion is `O(1)` on average.
- **Space Complexity: `O(n)`** — in the worst case, all numbers are distinct and all of them are stored in `set`.
