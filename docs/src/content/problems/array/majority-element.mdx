Given an array `nums` of size `n`, return _the majority element_.

The majority element is the element that appears more than `&lfloor;n / 2&rfloor;` times. You may assume that the majority element always exists in the array.

**Example 1:**

```
Input: nums = [3,2,3]
Output: 3
```
**Example 2:**

```
Input: nums = [2,2,1,1,1,2,2]
Output: 2
```

**Constraints:**

- `n == nums.length`

- `1 <= n <= 5 * 10^4`

- `-10^9 <= nums[i] <= 10^9`

- The input is generated such that a majority element will exist in the array.

**Follow-up:** Could you solve the problem in linear time and in `O(1)` space?

## Java Solution

```java
package array;

public class MajorityElement {
    public int majorityElement(int[] nums) {
        int count = 0;
        int candidate = 0;
        for (int num : nums) {
            if (count == 0) {
                candidate = num;
            }
            count += (num == candidate) ? 1 : -1;
        }
        return candidate;
    }
}
```

## Explanation

### Problem Analysis
We need to return the element that appears more than `n / 2` times in the array. The problem guarantees that such an element always exists, so the main task is finding it efficiently without extra storage.

This is a well-known interview problem because the optimal solution is not based on counting frequencies in a map, but on recognizing a cancellation idea that leads to linear time and constant space.

### Approach
A straightforward solution would count frequencies with a `HashMap`, but that uses extra space. This code uses the Boyer-Moore Voting Algorithm, which keeps a current candidate and a vote balance.

Whenever the current number matches the candidate, the balance increases. When it differs, the balance decreases. Different values effectively cancel each other out, and because the majority element appears more than half the time, it cannot be fully canceled.

### Pattern Used
This solution uses the **Greedy** pattern through the **Boyer-Moore Voting Algorithm**.

### Key Insight
Pairing off different values removes one majority occurrence and one non-majority occurrence at a time, so the true majority element is the only value that can survive all cancellations.

### Code Walkthrough
The method `majorityElement(int[] nums)` starts with:

- `int count = 0;`
- `int candidate = 0;`

The `for (int num : nums)` loop scans the array once.

At each number, the code first checks:

- `if (count == 0) { candidate = num; }`

This means whenever the current vote balance is exhausted, the current number becomes the new candidate.

Then the code updates the balance with:

- `count += (num == candidate) ? 1 : -1;`

So:

- matching `candidate` adds one vote,
- a different number removes one vote.

No extra verification pass is needed here because the problem guarantees that a majority element exists.

After the loop finishes, the surviving `candidate` is returned.

### Example Walkthrough
Use **Example 2**:

- `nums = [2,2,1,1,1,2,2]`

Track `candidate` and `count`:

- Start: `candidate = 0`, `count = 0`
- Read `2`: `count == 0`, so `candidate = 2`; then `count = 1`
- Read `2`: matches `candidate`, so `count = 2`
- Read `1`: different, so `count = 1`
- Read `1`: different, so `count = 0`
- Read `1`: `count == 0`, so `candidate = 1`; then `count = 1`
- Read `2`: different, so `count = 0`
- Read `2`: `count == 0`, so `candidate = 2`; then `count = 1`

The final `candidate` is `2`, which is the correct majority element.

### Key Variables Explained
- `count`: current vote balance for the active candidate.
- `candidate`: value currently believed to be the majority element.
- `num`: current array element being used to reinforce or cancel the candidate.

### Why This Works
Every time the code sees a value different from `candidate`, it cancels one previous vote for that candidate. This models removing pairs of distinct elements from consideration.

Since the true majority element appears more than all other elements combined, it cannot be completely canceled by this process. Therefore, after the full scan, the remaining `candidate` must be the majority element.

### Trick Used
The trick is pairwise cancellation using the Boyer-Moore voting rule, which avoids any frequency map.

### Edge Cases Handled
- Single-element array: the first element becomes `candidate` and is returned.
- Majority spread across the array instead of clustered together: repeated resets still work because of the cancellation logic.
- Negative or large values: comparisons are value-based, so the algorithm works the same way.

### Complexity Analysis
- **Time Complexity: `O(n)`** — the array is scanned once, and each element causes only constant-time updates.
- **Space Complexity: `O(1)`** — only `count` and `candidate` are used beyond the input array.
