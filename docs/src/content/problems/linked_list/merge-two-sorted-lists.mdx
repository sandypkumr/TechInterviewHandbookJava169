You are given the heads of two sorted linked lists `list1` and `list2`.

Merge the two lists into one **sorted** list. The list should be made by splicing together the nodes of the first two lists.

Return _the head of the merged linked list_.

**Example 1:**

```
Input: list1 = [1,2,4], list2 = [1,3,4]
Output: [1,1,2,3,4,4]
```

**Example 2:**

```
Input: list1 = [], list2 = []
Output: []
```

**Example 3:**

```
Input: list1 = [], list2 = [0]
Output: [0]
```

**Constraints:**

- The number of nodes in both lists is in the range `[0, 50]`.

- `-100 <= Node.val <= 100`

- Both `list1` and `list2` are sorted in **non-decreasing** order.

**Patterns:** `merge-intervals`

## Java Solution

```java
package linked_list;

public class MergeTwoSortedLists {
    public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
        if (list1 == null) {
            return list2;
        }
        if (list2 == null) {
            return list1;
        }

        ListNode mergedHead = new ListNode(0);
        ListNode current = mergedHead;

        while (list1 != null && list2 != null) {
            if (list1.val < list2.val) {
                current.next = list1;
                list1 = list1.next;
            } else {
                current.next = list2;
                list2 = list2.next;
            }
            current = current.next;
        }

        if (list1 != null) {
            current.next = list1;
        } else {
            current.next = list2;
        }

        return mergedHead.next;
    }
}
```

## Explanation

### Approach

**Merge Two Sorted Lists** exploits sorted order (or a structural property) to let two pointers converge from opposite ends of the array, eliminating the need for a nested loop. When the current pair doesn't satisfy the condition, we know exactly which pointer to advance — so each element is visited at most once, giving O(n) time.

Imagine squeezing a tube of toothpaste from both ends simultaneously — instead of trying every possible pair (both ends → O(n²)), you make an informed decision at each step about which end to squeeze next.

### Code Walkthrough

The solution is implemented in `mergeTwoLists(ListNode list1, ListNode list2)`:

1. Sort the array if it isn't already (or confirm the existing order guarantees correctness).
2. Place one pointer at the start (left = 0) and one at the end (right = n - 1).
3. Compute the result for the current pair.
4. If the result is too small, advance left to increase it; if too large, move right backward.
5. Stop when the pointers meet or cross.

### Complexity Analysis

- **Time Complexity: `O(n+m)`** — see the analysis for full details.
- **Space Complexity: `O(1)`** — only a fixed number of extra variables are used; no data structures that scale with input.
