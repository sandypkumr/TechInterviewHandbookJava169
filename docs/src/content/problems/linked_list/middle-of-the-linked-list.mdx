Given the `head` of a singly linked list, return _the middle node of the linked list_.

If there are two middle nodes, return **the second middle** node.

**Example 1:**

```
Input: head = [1,2,3,4,5]
Output: [3,4,5]
Explanation: The middle node of the list is node 3.
```

**Example 2:**

```
Input: head = [1,2,3,4,5,6]
Output: [4,5,6]
Explanation: Since the list has two middle nodes with values 3 and 4, we return the second one.
```

**Constraints:**

- The number of nodes in the list is in the range `[1, 100]`.

- `1 <= Node.val <= 100`

**Patterns:** `two-pointers`, `fast-slow-pointers`

## Java Solution

```java
package linked_list;

public class MiddleOfTheLinkedList {
    public ListNode middleNode(ListNode head) {
        ListNode slow = head;
        ListNode fast = head;

        // Move fast pointer two steps and slow pointer one step
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }

        return slow; // Slow pointer is now at the middle node
    }
}
```

## Explanation

### Approach

**Middle of the Linked List** uses two pointers moving at different speeds — slow advances one step at a time, fast advances two. If a cycle exists, the fast pointer eventually laps the slow pointer and they meet inside the cycle. If no cycle exists, fast reaches the end first.

Think of two runners on a circular track: the faster runner will always eventually overtake (lap) the slower one. If the track has no loop (i.e., it ends), the faster runner simply reaches the finish line first.

### Code Walkthrough

The solution is implemented in `middleNode(ListNode head)`:

1. Initialise slow = head and fast = head.
2. Advance slow by one step and fast by two steps each iteration.
3. If fast or fast.next is null, there is no cycle.
4. If slow == fast, a cycle is detected (meeting point is inside the cycle).
5. To find the cycle entry point, reset one pointer to head and advance both one step at a time.

### Complexity Analysis

- **Time Complexity: `O(n)`** — the input is processed in a single linear pass.
- **Space Complexity: `O(1)`** — only a fixed number of extra variables are used; no data structures that scale with input.
