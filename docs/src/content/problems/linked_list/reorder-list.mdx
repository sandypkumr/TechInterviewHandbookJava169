You are given the head of a singly linked-list. The list can be represented as:

```
L0 &rarr; L1 &rarr; &hellip; &rarr; Ln - 1 &rarr; Ln
```

_Reorder the list to be on the following form:_

```
L0 &rarr; Ln &rarr; L1 &rarr; Ln - 1 &rarr; L2 &rarr; Ln - 2 &rarr; &hellip;
```

You may not modify the values in the list's nodes. Only nodes themselves may be changed.

**Example 1:**

```
Input: head = [1,2,3,4]
Output: [1,4,2,3]
```

**Example 2:**

```
Input: head = [1,2,3,4,5]
Output: [1,5,2,4,3]
```

**Constraints:**

- The number of nodes in the list is in the range `[1, 5 * 10^4]`.

- `1 <= Node.val <= 1000`

**Patterns:** `two-pointers`, `fast-slow-pointers`

## Java Solution

```java
package linked_list;

public class ReorderList {
    public void reorderList(ListNode head) {
        if (head == null || head.next == null) {
            return;
        }

        // Step 1: Find the middle of the list
        ListNode slow = head;
        ListNode fast = head;
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }

        // Step 2: Reverse the second half of the list
        ListNode prev = null;
        ListNode curr = slow;
        while (curr != null) {
            ListNode nextTemp = curr.next;
            curr.next = prev;
            prev = curr;
            curr = nextTemp;
        }

        // Step 3: Merge the two halves
        ListNode first = head;
        ListNode second = prev;

        while (second != null) {
            ListNode temp1 = first.next;
            ListNode temp2 = second.next;

            first.next = second;
            if (second != temp1) {
                second.next  = temp1;
            }

            first = temp1;
            second = temp2;
        }
    }
}
```

## Explanation

### Approach

**Reorder List** uses two pointers moving at different speeds — slow advances one step at a time, fast advances two. If a cycle exists, the fast pointer eventually laps the slow pointer and they meet inside the cycle. If no cycle exists, fast reaches the end first.

Think of two runners on a circular track: the faster runner will always eventually overtake (lap) the slower one. If the track has no loop (i.e., it ends), the faster runner simply reaches the finish line first.

### Code Walkthrough

The solution is implemented in `reorderList(ListNode head)`:

1. Initialise slow = head and fast = head.
2. Advance slow by one step and fast by two steps each iteration.
3. If fast or fast.next is null, there is no cycle.
4. If slow == fast, a cycle is detected (meeting point is inside the cycle).
5. To find the cycle entry point, reset one pointer to head and advance both one step at a time.

> **Note:** This solution also uses the **two pointers moving toward each other** technique.

### Complexity Analysis

- **Time Complexity: `O(n)`** — the two pointers together traverse the array at most once — every element is visited at most twice.
- **Space Complexity: `O(1)`** — only a fixed number of extra variables are used; no data structures that scale with input.
