Given the `head` of a singly linked list, return `true`_ if it is a __palindrome__ or _`false`_ otherwise_.

**Example 1:**

```
Input: head = [1,2,2,1]
Output: true
```

**Example 2:**

```
Input: head = [1,2]
Output: false
```

**Constraints:**

- The number of nodes in the list is in the range `[1, 10^5]`.

- `0 <= Node.val <= 9`

**Follow up:** Could you do it in `O(n)` time and `O(1)` space?

**Patterns:** `sliding-window`, `two-pointers`, `fast-slow-pointers`

## Java Solution

```java
package linked_list;

public class PalindromeLinkedList {
    public boolean isPalindrome(ListNode head) {
        // Step 1: Find the middle of the linked list
        ListNode slow = head;
        ListNode fast = head;

        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }

        // Step 2: Reverse the second half of the linked list
        ListNode prev = null;
        ListNode current = slow;

        while (current != null) {
            ListNode nextTemp = current.next; // Store next node
            current.next = prev; // Reverse the link
            prev = current; // Move prev to current
            current = nextTemp; // Move to the next node
        }

        // Step 3: Compare the first half and the reversed second half
        ListNode left = head;
        ListNode right = prev; // Start of the reversed second half

        while (right != null) {
            if (left.val != right.val) {
                return false; // Not a palindrome
            }
            left = left.next;
            right = right.next;
        }

        return true; // Is a palindrome
    }
}
```
