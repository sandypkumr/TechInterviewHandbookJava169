Design a stack-like data structure to push elements to the stack and pop the most frequent element from the stack.

Implement the `FreqStack` class:

- `FreqStack()` constructs an empty frequency stack.

- `void push(int val)` pushes an integer `val` onto the top of the stack.

- `int pop()` removes and returns the most frequent element in the stack.

		If there is a tie for the most frequent element, the element closest to the stack's top is removed and returned.

**Example 1:**

```
Input
["FreqStack", "push", "push", "push", "push", "push", "push", "pop", "pop", "pop", "pop"]
[[], [5], [7], [5], [7], [4], [5], [], [], [], []]
Output
[null, null, null, null, null, null, null, 5, 7, 5, 4]

Explanation
FreqStack freqStack = new FreqStack();
freqStack.push(5); // The stack is [5]
freqStack.push(7); // The stack is [5,7]
freqStack.push(5); // The stack is [5,7,5]
freqStack.push(7); // The stack is [5,7,5,7]
freqStack.push(4); // The stack is [5,7,5,7,4]
freqStack.push(5); // The stack is [5,7,5,7,4,5]
freqStack.pop();   // return 5, as 5 is the most frequent. The stack becomes [5,7,5,7,4].
freqStack.pop();   // return 7, as 5 and 7 is the most frequent, but 7 is closest to the top. The stack becomes [5,7,5,4].
freqStack.pop();   // return 5, as 5 is the most frequent. The stack becomes [5,7,4].
freqStack.pop();   // return 4, as 4, 5 and 7 is the most frequent, but 4 is closest to the top. The stack becomes [5,7].
```

**Constraints:**

- `0 <= val <= 10^9`

- At most `2 * 10^4` calls will be made to `push` and `pop`.

- It is guaranteed that there will be at least one element in the stack before calling `pop`.

## Java Solution

```java
package stack;

import java.util.HashMap;
import java.util.Map;
import java.util.Stack;

public class MaximumFrequencyStack {
    private Map<Integer, Integer> frequencyMap;
    private Map<Integer, Stack<Integer>> groupMap;
    private int maxFrequency;

    public MaximumFrequencyStack() {
        frequencyMap = new HashMap<>();
        groupMap = new HashMap<>();
        maxFrequency = 0;
    }

    public void push(int val) {
        int frequency = frequencyMap.getOrDefault(val, 0) + 1;
        frequencyMap.put(val, frequency);
        maxFrequency = Math.max(maxFrequency, frequency);
        groupMap.computeIfAbsent(frequency, k -> new Stack<>()).push(val);
    }

    public int pop() {
        Stack<Integer> stack = groupMap.get(maxFrequency);
        int val = stack.pop();
        if (stack.isEmpty()) {
            groupMap.remove(maxFrequency);
            maxFrequency--;
        }
        frequencyMap.put(val, frequencyMap.get(val) - 1);
        return val;
    }
}
```

## Explanation

### Problem Analysis

This design problem asks for stack behavior with a non-standard pop rule: remove the most frequent value, and if frequencies tie, remove the one closest to the top. So we must preserve both frequency information and recency information at the same time.

It is a strong interview question because it tests whether you can combine multiple data structures to satisfy two priorities efficiently.

### Approach

The code separates the problem into two layers:

- `frequencyMap` tracks how many times each value currently appears.
- `groupMap` stores a stack for each frequency, so all values that currently reached frequency `1`, `2`, `3`, and so on are grouped separately.

`maxFrequency` tells us which frequency bucket should be popped from next. This is much better than scanning all values on every `pop()`.

### Pattern Used

This solution uses a **Hash Map + Stack grouping** pattern.

### Key Insight

If every value is pushed onto the stack for its new frequency, then the stack at `maxFrequency` automatically keeps the correct tie-break order: the most recently pushed among the most frequent values is on top.

### Code Walkthrough

The class maintains three fields:

- `Map<Integer, Integer> frequencyMap;`
- `Map<Integer, Stack<Integer>> groupMap;`
- `int maxFrequency;`

In the constructor:

- both maps are initialized
- `maxFrequency = 0`

In `push(int val)`:

- `int frequency = frequencyMap.getOrDefault(val, 0) + 1;`
  - this computes the new frequency after inserting `val`
- `frequencyMap.put(val, frequency);`
  - store the updated count
- `maxFrequency = Math.max(maxFrequency, frequency);`
  - update the global highest frequency if needed
- `groupMap.computeIfAbsent(frequency, k -> new Stack<>()).push(val);`
  - place `val` into the stack that represents its new frequency

In `pop()`:

- `Stack<Integer> stack = groupMap.get(maxFrequency);`
  - get the bucket for the current highest frequency
- `int val = stack.pop();`
  - remove the most recent value from that bucket
- If that bucket becomes empty:
  - `groupMap.remove(maxFrequency);`
  - `maxFrequency--;`
- Finally:
  - `frequencyMap.put(val, frequencyMap.get(val) - 1);`
  - decrease the stored count for the returned value
- `return val;`

### Example Walkthrough

Using the given example:

- `push(5)`  
  - `frequencyMap[5] = 1`
  - `groupMap[1] = [5]`
  - `maxFrequency = 1`
- `push(7)`  
  - `frequencyMap[7] = 1`
  - `groupMap[1] = [5, 7]`
- `push(5)`  
  - `frequencyMap[5] = 2`
  - `groupMap[2] = [5]`
  - `maxFrequency = 2`
- `push(7)`  
  - `frequencyMap[7] = 2`
  - `groupMap[2] = [5, 7]`
- `push(4)`  
  - `frequencyMap[4] = 1`
  - `groupMap[1] = [5, 7, 4]`
- `push(5)`  
  - `frequencyMap[5] = 3`
  - `groupMap[3] = [5]`
  - `maxFrequency = 3`

Now pops:

- first `pop()`  
  - use `groupMap[3]`, pop `5`
  - `maxFrequency` drops to `2`
- second `pop()`  
  - use `groupMap[2] = [5, 7]`
  - pop `7` because it is closer to the top among frequency-2 values
- third `pop()`  
  - still use frequency `2`
  - pop `5`
- fourth `pop()`  
  - all remaining values have frequency `1`
  - `groupMap[1]` returns `4`, which is the most recent among them

That matches the expected output `5, 7, 5, 4`.

### Key Variables Explained

- `frequencyMap`: current count for each value.
- `groupMap`: maps a frequency to a stack of values that reached that frequency.
- `maxFrequency`: highest frequency currently present in the structure.
- `frequency`: local variable in `push(int val)` representing the new count after insertion.
- `stack`: local variable in `pop()` representing the stack for `maxFrequency`.
- `val`: the pushed or popped value being processed.

### Why This Works

`frequencyMap` guarantees that the structure always knows each value's current count. `groupMap` guarantees that values with the same count are ordered by recency, because every `push` appends the value to the stack of its new frequency.

Therefore:

- the correct frequency to pop from is always `maxFrequency`
- the correct tie-break choice is always the top of `groupMap.get(maxFrequency)`

When a bucket becomes empty after popping, decreasing `maxFrequency` is safe because no element with that higher count remains.

### Trick Used

The trick is **grouping values by frequency into stacks**, which lets the same data structure handle both priorities: highest frequency first, most recent among ties second.

### Edge Cases Handled

- Frequency ties: resolved automatically because each frequency bucket is a `Stack<Integer>`.
- Transition to a lower maximum frequency: when `groupMap.get(maxFrequency)` becomes empty, the code removes that bucket and decrements `maxFrequency`.
- Repeated pushes of the same value: `frequencyMap` correctly accumulates the count and moves the value into higher-frequency buckets.

The code relies on the problem guarantee that `pop()` is only called when at least one element exists.

### Complexity Analysis

- **Time Complexity: `O(1)` per `push()` and `pop()`**  
  Each operation performs a constant number of hash map lookups/updates and stack push/pop operations.
- **Space Complexity: `O(n)`**  
  `frequencyMap` stores counts per distinct value, and `groupMap` collectively stores one entry for each push currently represented in the structure.
