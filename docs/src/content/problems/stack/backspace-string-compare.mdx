Given two strings `s` and `t`, return `true` _if they are equal when both are typed into empty text editors_. `'#'` means a backspace character.

Note that after backspacing an empty text, the text will continue empty.

**Example 1:**

```
Input: s = "ab#c", t = "ad#c"
Output: true
Explanation: Both s and t become "ac".
```

**Example 2:**

```
Input: s = "ab##", t = "c#d#"
Output: true
Explanation: Both s and t become "".
```

**Example 3:**

```
Input: s = "a#c", t = "b"
Output: false
Explanation: s becomes "c" while t becomes "b".
```

**Constraints:**

- `1 <= s.length, t.length <= 200`

- `s` and `t` only contain lowercase letters and `'#'` characters.

**Follow up:** Can you solve it in `O(n)` time and `O(1)` space?

## Java Solution

```java
package stack;

public class BackspaceStringCompare {
    public boolean backspaceCompare(String s, String t) {
        return buildString(s).equals(buildString(t));
    }

    private String buildString(String str) {
        StringBuilder sb = new StringBuilder();
        int skip = 0;

        for (int i = str.length() - 1; i >= 0; i--) {
            char c = str.charAt(i);
            if (c == '#') {
                skip++;
            } else if (skip > 0) {
                skip--;
            } else {
                sb.append(c);
            }
        }

        return sb.toString();
    }
}
```

## Explanation

### Approach

**Backspace String Compare** exploits sorted order (or a structural property) to let two pointers converge from opposite ends of the array, eliminating the need for a nested loop. When the current pair doesn't satisfy the condition, we know exactly which pointer to advance — so each element is visited at most once, giving O(n) time.

Imagine squeezing a tube of toothpaste from both ends simultaneously — instead of trying every possible pair (both ends → O(n²)), you make an informed decision at each step about which end to squeeze next.

### Code Walkthrough

The solution is implemented in `backspaceCompare(String s, String t)`:

1. Sort the array if it isn't already (or confirm the existing order guarantees correctness).
2. Place one pointer at the start (left = 0) and one at the end (right = n - 1).
3. Compute the result for the current pair.
4. If the result is too small, advance left to increase it; if too large, move right backward.
5. Stop when the pointers meet or cross.

### Complexity Analysis

- **Time Complexity: `O(n)`** — the two pointers together traverse the array at most once — every element is visited at most twice.
- **Space Complexity: `O(n)`** — auxiliary space proportional to the input size is used.
