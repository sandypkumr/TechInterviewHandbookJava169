Given a string containing just the characters `'('` and `')'`, return _the length of the longest valid (well-formed) parentheses __substring_.

**Example 1:**

```
Input: s = "(()"
Output: 2
Explanation: The longest valid parentheses substring is "()".
```

**Example 2:**

```
Input: s = ")()())"
Output: 4
Explanation: The longest valid parentheses substring is "()()".
```

**Example 3:**

```
Input: s = ""
Output: 0
```

**Constraints:**

- `0 <= s.length <= 3 * 10^4`

- `s[i]` is `'('`, or `')'`.

## Java Solution

```java
package stack;

import java.util.Stack;

public class LongestValidParentheses {
    public int longestValidParentheses(String s) {
        Stack<Integer> stack = new Stack<>();
        stack.push(-1);
        int maxLength = 0;
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c == '(') {
                stack.push(i);
            } else {
                stack.pop();
                if (stack.isEmpty()) {
                    stack.push(i);
                } else {
                    maxLength = Math.max(maxLength, i - stack.peek());
                }
            }
        }
        return maxLength;
    }
}
```

## Explanation

### Approach

**Longest Valid Parentheses** exploits sorted order (or a structural property) to let two pointers converge from opposite ends of the array, eliminating the need for a nested loop. When the current pair doesn't satisfy the condition, we know exactly which pointer to advance — so each element is visited at most once, giving O(n) time.

Imagine squeezing a tube of toothpaste from both ends simultaneously — instead of trying every possible pair (both ends → O(n²)), you make an informed decision at each step about which end to squeeze next.

### Code Walkthrough

The solution is implemented in `longestValidParentheses(String s)`:

1. Sort the array if it isn't already (or confirm the existing order guarantees correctness).
2. Place one pointer at the start (left = 0) and one at the end (right = n - 1).
3. Compute the result for the current pair.
4. If the result is too small, advance left to increase it; if too large, move right backward.
5. Stop when the pointers meet or cross.

### Complexity Analysis

- **Time Complexity: `O(n)`** — the two pointers together traverse the array at most once — every element is visited at most twice.
- **Space Complexity: `O(1)`** — only a fixed number of extra variables are used; no data structures that scale with input.
