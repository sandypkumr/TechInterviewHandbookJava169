Given an integer array `nums`, return `true` _if you can partition the array into two subsets such that the sum of the elements in both subsets is equal or _`false`_ otherwise_.

**Example 1:**

```
Input: nums = [1,5,11,5]
Output: true
Explanation: The array can be partitioned as [1, 5, 5] and [11].
```

**Example 2:**

```
Input: nums = [1,2,3,5]
Output: false
Explanation: The array cannot be partitioned into equal sum subsets.
```

**Constraints:**

- `1 <= nums.length <= 200`

- `1 <= nums[i] <= 100`

**Patterns:** `dynamic-programming`

## Java Solution

```java
package dynamic_programming;

public class PartitionEqualSubsetSum {
    public boolean canPartition(int[] nums) {
        int totalSum = 0;
        for (int num : nums) {
            totalSum += num;
        }

        if (totalSum % 2 != 0) {
            return false;
        }

        int target = totalSum / 2;
        boolean[] dp = new boolean[target + 1];
        dp[0] = true;

        for (int num : nums) {
            for (int j = target; j >= num; j--) {
                dp[j] = dp[j] || dp[j - num];
            }
        }

        return dp[target];
    }
}
```

## Explanation

### Approach

**Partition Equal Subset Sum** has optimal substructure: the answer to the full problem can be built from answers to smaller sub-problems. Without memoisation, a naive recursion solves the same sub-problem exponentially many times; DP stores each result once and reuses it in O(1).

Think of computing Fibonacci numbers: fib(5) needs fib(4) and fib(3), which both need fib(2) — without caching you'd compute fib(2) repeatedly. DP caches each sub-answer so every value is computed exactly once, reducing exponential work to polynomial.

### Code Walkthrough

The solution is implemented in `canPartition(int[] nums)`:

1. Define the state: what does dp[i] (or dp[i][j]) represent?
2. Write the recurrence relation that builds dp[i] from previously computed states.
3. Identify and set the base cases (dp[0], dp[1], etc.).
4. Fill the table bottom-up (or top-down with memoisation) in the correct order.
5. Read off the final answer from dp[n] (or dp[m][n] for 2-D problems).

- **Time Complexity: `O(n·W)`** — see the analysis for full details.
- **Space Complexity: `O(W)`** — auxiliary space proportional to the input is required.
