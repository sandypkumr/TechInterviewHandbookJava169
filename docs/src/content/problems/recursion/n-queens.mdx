The **n-queens** puzzle is the problem of placing `n` queens on an `n x n` chessboard such that no two queens attack each other.

Given an integer `n`, return _all distinct solutions to the **n-queens puzzle**_. You may return the answer in **any order**.

Each solution contains a distinct board configuration of the n-queens' placement, where `'Q'` and `'.'` both indicate a queen and an empty space, respectively.

**Example 1:**

```
Input: n = 4
Output: [[".Q..","...Q","Q...","..Q."],["..Q.","Q...","...Q",".Q.."]]
Explanation: There exist two distinct solutions to the 4-queens puzzle as shown above
```

**Example 2:**

```
Input: n = 1
Output: [["Q"]]
```

**Constraints:**

- `1 <= n <= 9`

**Patterns:** `sliding-window`, `backtracking`

## Java Solution

```java
package recursion;

import java.util.*;

public class NQueens {
    public List<List<String>> solveNQueens(int n) {
        List<List<String>> result = new ArrayList<>();
        char[][] board = new char[n][n];

        for (int i = 0; i < n; i++) {
            Arrays.fill(board[i], '.');
        }

        Set<Integer> cols = new HashSet<>();
        Set<Integer> diag1 = new HashSet<>();
        Set<Integer> diag2 = new HashSet<>();

        backtrack(0, n, board, cols, diag1, diag2, result);
        return result;
    }

    private void backtrack(int row, int n, char[][] board, Set<Integer> cols, Set<Integer> diag1,
                           Set<Integer> diag2, List<List<String>> result) {
        if (row == n) {
            List<String> solution = new ArrayList<>();
            for (int i = 0; i < n; i++) {
                solution.add(new String(board[i]));
            }
            result.add(solution);
            return;
        }

        for (int col = 0; col < n; col++) {
            if (cols.contains(col) || diag1.contains(row - col) || diag2.contains(row + col)) {
                continue;
            }

            board[row][col] = 'Q';
            cols.add(col);
            diag1.add(row - col);
            diag2.add(row + col);

            backtrack(row + 1, n, board, cols, diag1, diag2, result);

            board[row][col] = '.';
            cols.remove(col);
            diag1.remove(row - col);
            diag2.remove(row + col);
        }
    }
}
```

## Explanation

### Problem Analysis
The problem asks us to place `n` queens on an `n x n` board so that no two queens share the same column, main diagonal, or anti-diagonal. We must return every valid board configuration, not just count them.

This is a classic interview problem because it combines backtracking with constraint checking and shows whether you can prune invalid states early instead of exploring impossible boards.

### Approach
The code places queens row by row. For each row, it tries every column, but it only places a queen if that column and both diagonals are currently unused.

This is much better than generating all possible board arrangements and checking them afterward. By rejecting bad positions immediately, the recursion only continues down states that can still become valid solutions.

### Pattern Used
Backtracking with hash-set based constraint tracking.

### Key Insight
Once queens are placed in earlier rows, a position `(row, col)` is safe if and only if `col`, `row - col`, and `row + col` are all unused.

### Code Walkthrough
In `solveNQueens(int n)`:
- `result` stores all finished boards.
- `char[][] board = new char[n][n]` creates the chessboard.
- The `for` loop with `Arrays.fill(board[i], '.')` initializes every cell as empty.
- `cols`, `diag1`, and `diag2` track which columns and diagonals are already occupied by queens.
- `backtrack(0, n, board, cols, diag1, diag2, result)` starts from the first row.

In `backtrack(...)`:
- `row` tells us which row we are trying to fill next.
- The base case is `if (row == n)`.
- At that point, all rows contain a queen, so the code converts each `board[i]` row into a `String` and adds the resulting `List<String>` to `result`.

For each column in the current row:
- The loop `for (int col = 0; col < n; col++)` tries all candidate placements.
- `if (cols.contains(col) || diag1.contains(row - col) || diag2.contains(row + col))` skips unsafe positions.
- If safe, the code places a queen with `board[row][col] = 'Q'`.
- It marks the attack paths by adding to `cols`, `diag1`, and `diag2`.
- Then it recurses to `row + 1`.
- After recursion, it removes the queen and unmarks those sets so other columns in the same row can be explored.

### Example Walkthrough
Use **Example 1**: `n = 4`.

One successful branch is:
- `row = 0`, place queen at `(0,1)` -> `cols = {1}`, `diag1 = {-1}`, `diag2 = {1}`
- `row = 1`, columns `0`, `1`, `2` are unsafe, so place at `(1,3)` -> `cols = {1,3}`, `diag1 = {-1,-2}`, `diag2 = {1,4}`
- `row = 2`, place at `(2,0)` -> `cols = {1,3,0}`, `diag1 = {-1,-2,2}`, `diag2 = {1,4,2}`
- `row = 3`, place at `(3,2)` -> `cols = {1,3,0,2}`, `diag1 = {-1,-2,2,1}`, `diag2 = {1,4,2,5}`

Now `row == n`, so the board is recorded as:
- `".Q.."`
- `"...Q"`
- `"Q..."`
- `"..Q."`

Backtracking then continues to find the second valid arrangement:
- `"..Q."`, `"Q..."`, `"...Q"`, `".Q.."`

### Key Variables Explained
- `board`: mutable chessboard used during the search.
- `result`: all valid boards found so far.
- `row`: the next row that must receive a queen.
- `cols`: columns that already contain a queen.
- `diag1`: main diagonals identified by `row - col`.
- `diag2`: anti-diagonals identified by `row + col`.
- `col`: candidate column being tested in the current row.

### Why This Works
The recursion maintains a strong invariant: before `backtrack(row, ...)` begins, every row from `0` to `row - 1` contains exactly one queen, and none of those queens attack each other.

The set checks ensure a queen is only placed where it is safe relative to all previously placed queens. Since each recursive call advances to the next row, every completed board has exactly `n` queens, one per row. Since the loop tries every column in every reachable row, every valid arrangement is explored, and invalid partial boards are pruned immediately.

### Trick Used
The diagonal encoding is the main trick: all cells on one main diagonal share `row - col`, and all cells on one anti-diagonal share `row + col`.

### Edge Cases Handled
- `n = 1`: the algorithm places one queen, reaches `row == n`, and returns `[["Q"]]`.
- Dead-end partial boards: the `continue` statement skips attacked cells, and if no column works, recursion naturally backtracks.
- Board construction for output: each solved `char[]` row is copied into a new `String`, so stored solutions are not corrupted by later backtracking.

### Complexity Analysis
- **Time Complexity:** worst-case `O(n!)`, which is the standard upper bound for row-by-row backtracking here. Additionally, converting one completed board into strings costs `O(n^2)` per stored solution.
- **Space Complexity:** `O(n^2)` for `board` plus `O(n)` recursion depth and up to `O(n)` entries in each of `cols`, `diag1`, and `diag2`, excluding the output list.
