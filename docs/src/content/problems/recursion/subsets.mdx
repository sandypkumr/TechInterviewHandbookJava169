Given an integer array `nums` of **unique** elements, return _all possible_ _subsets_ _(the power set)_.

The solution set **must not** contain duplicate subsets. Return the solution in **any order**.

**Example 1:**

```
Input: nums = [1,2,3]
Output: [[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]
```

**Example 2:**

```
Input: nums = [0]
Output: [[],[0]]
```

**Constraints:**

- `1 <= nums.length <= 10`

- `-10 <= nums[i] <= 10`

- All the numbers of `nums` are **unique**.

**Patterns:** `backtracking`

## Java Solution

```java
package recursion;

import java.util.ArrayList;
import java.util.List;

public class Subsets {
    public List<List<Integer>> subsets(int[] nums) {
        List<List<Integer>> result = new ArrayList<>();
        int n = nums.length;
        int total = 1 << n;

        for (int mask = 0; mask < total; mask++) {
            List<Integer> subset = new ArrayList<>();
            for (int i = 0; i < n; i++) {
                if ((mask & (1 << i)) != 0) {
                    subset.add(nums[i]);
                }
            }
            result.add(subset);
        }

        return result;
    }
}
```

## Explanation

### Problem Analysis
This problem asks for the full power set of `nums`, meaning every possible subset, including the empty set and the full array. Because each number is unique, every subset can be described simply by whether each index is included or excluded.

It is a common interview question because it tests whether you recognize subset generation patterns and can map combinatorial choices to efficient code.

### Approach
This implementation does not use recursion. Instead, it uses a bitmask from `0` to `(1 << n) - 1`, where each bit represents whether the corresponding element of `nums` is present in the current subset.

That choice is cleaner than recursive branching for this exact code because every subset corresponds to one integer mask. Iterating through masks guarantees that all subsets are generated exactly once.

### Pattern Used
Primarily relies on direct iteration with bit manipulation.

### Key Insight
A subset of `n` elements can be encoded as an `n`-bit number, where bit `i` tells us whether `nums[i]` belongs to that subset.

### Code Walkthrough
In `subsets(int[] nums)`:
- `result` stores every generated subset.
- `n = nums.length` stores the number of available elements.
- `total = 1 << n` computes `2^n`, the total number of subsets.

Outer loop:
- `for (int mask = 0; mask < total; mask++)` iterates through every possible bit pattern from all-zeroes to all-ones.
- For each `mask`, the code creates a fresh `subset` list.

Inner loop:
- `for (int i = 0; i < n; i++)` checks every bit position.
- `if ((mask & (1 << i)) != 0)` means bit `i` is set.
- When that condition is true, `nums[i]` is included in the current `subset`.

After checking all positions:
- `result.add(subset)` stores the subset represented by the current bitmask.
- After the outer loop finishes, `result` contains all subsets.

### Example Walkthrough
Use **Example 1**: `nums = [1,2,3]`.

Here `n = 3`, so:
- `total = 1 << 3 = 8`
- masks go from `0` to `7`

Mask by mask:
- `mask = 0` (`000`) -> include nothing -> `[]`
- `mask = 1` (`001`) -> include `nums[0]` -> `[1]`
- `mask = 2` (`010`) -> include `nums[1]` -> `[2]`
- `mask = 3` (`011`) -> include `nums[0]` and `nums[1]` -> `[1,2]`
- `mask = 4` (`100`) -> include `nums[2]` -> `[3]`
- `mask = 5` (`101`) -> include `nums[0]` and `nums[2]` -> `[1,3]`
- `mask = 6` (`110`) -> include `nums[1]` and `nums[2]` -> `[2,3]`
- `mask = 7` (`111`) -> include all three -> `[1,2,3]`

That matches the example output.

### Key Variables Explained
- `result`: final list of all subsets.
- `n`: number of input elements.
- `total`: number of masks, equal to `2^n`.
- `mask`: integer whose bits encode one subset.
- `subset`: the actual list built for the current `mask`.
- `i`: current element/bit position being inspected.

### Why This Works
For every index `i`, a subset has exactly two choices: either include `nums[i]` or do not include it. An `n`-bit mask captures those choices perfectly.

Because the outer loop visits every mask from `0` to `2^n - 1`, every possible combination of include/exclude decisions appears exactly once. The inner loop decodes that mask consistently, so each produced `subset` matches one and only one bit pattern.

### Trick Used
The bitmask trick: `(mask & (1 << i)) != 0` efficiently checks whether `nums[i]` belongs to the current subset.

### Edge Cases Handled
- Single-element input like `[0]`: `total` becomes `2`, so the code naturally returns `[]` and `[0]`.
- Empty subset: produced when `mask = 0`.
- Full subset: produced when all bits are set, meaning `mask = total - 1`.
- Negative values in `nums`: handled normally because the algorithm only checks indices and bits, not numeric ordering.

### Complexity Analysis
- **Time Complexity:** `O(n * 2^n)`. There are `2^n` masks, and for each one the inner loop scans all `n` positions.
- **Space Complexity:** `O(1)` auxiliary space excluding the output. Aside from loop variables and one temporary `subset` per iteration, the algorithm does not use recursion or extra structures that scale with `n`. The returned `result` itself stores `2^n` subsets.
