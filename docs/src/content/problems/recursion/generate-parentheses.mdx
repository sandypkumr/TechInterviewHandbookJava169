Given `n` pairs of parentheses, write a function to _generate all combinations of well-formed parentheses_.

**Example 1:**

```
Input: n = 3
Output: ["((()))","(()())","(())()","()(())","()()()"]
```
**Example 2:**

```
Input: n = 1
Output: ["()"]
```

**Constraints:**

- `1 <= n <= 8`

**Patterns:** `backtracking`

## Java Solution

```java
package recursion;

import java.util.ArrayList;
import java.util.List;

public class GenerateParentheses {
    public List<String> generateParenthesis(int n) {
        List<String> result = new ArrayList<>();
        backtrack(result,"", 0, 0, n);
        return result;
    }

    private void backtrack(List<String> result, String current, int open, int close, int max) {
        if (current.length() == max * 2) {
            result.add(current);
            return;
        }

        if (open < max) {
            backtrack(result, current + "(", open + 1, close, max);
        }
        if (close < open) {
            backtrack(result, current + ")", open, close + 1, max);
        }
    }
}
```

## Explanation

### Approach

**Generate Parentheses** requires enumerating all valid combinations/permutations/subsets. Backtracking systematically tries every candidate and immediately abandons ("prunes") any branch that cannot possibly lead to a valid solution, making it far faster than brute-force enumeration in practice.

Think of solving a sudoku: you place a digit, recursively try to solve the rest, and if you reach a contradiction you erase that digit (backtrack) and try the next. The key is that pruning can cut enormous branches of the search tree early.

### Code Walkthrough

The solution is implemented in `generateParenthesis(int n)`:

1. Define what constitutes a valid complete solution (base case).
2. At each step, iterate over all possible next choices.
3. Apply a choice (mutate state), then recurse.
4. After recursion returns, undo the choice (backtrack) to restore state.
5. Apply a pruning condition to skip choices that cannot lead to a valid solution.

### Complexity Analysis

- **Time Complexity: `O(4^n / sqrt(n))`** — see the analysis for full details.
- **Space Complexity: `O(n)`** — auxiliary space proportional to the input size is used.
