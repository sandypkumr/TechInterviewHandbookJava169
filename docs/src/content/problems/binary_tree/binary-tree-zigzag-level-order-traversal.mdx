Given the `root` of a binary tree, return _the zigzag level order traversal of its nodes' values_. (i.e., from left to right, then right to left for the next level and alternate between).

**Example 1:**

```
Input: root = [3,9,20,null,null,15,7]
Output: [[3],[20,9],[15,7]]
```

**Example 2:**

```
Input: root = [1]
Output: [[1]]
```

**Example 3:**

```
Input: root = []
Output: []
```

**Constraints:**

- The number of nodes in the tree is in the range `[0, 2000]`.

- `-100 <= Node.val <= 100`

## Java Solution

```java
package binary_tree;

import java.util.ArrayList;
import java.util.LinkedList;
import java.util.List;
import java.util.Queue;

public class BinaryTreeZigzagLevelOrderTraversal {
    public List<List<Integer>> zigzagLevelOrder(TreeNode root) {
        List<List<Integer>> result = new ArrayList<>();
        if (root == null) {
            return result;
        }
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);
        boolean leftToRight = true;
        while (!queue.isEmpty()) {
            int levelSize = queue.size();
            LinkedList<Integer> levelList = new LinkedList<>();
            for (int i = 0; i < levelSize; i++) {
                TreeNode node = queue.poll();
                if (leftToRight) {
                    levelList.addLast(node.val);
                } else {
                    levelList.addFirst(node.val);
                }
                if (node.left != null) {
                    queue.offer(node.left);
                }
                if (node.right != null) {
                    queue.offer(node.right);
                }
            }
            result.add(levelList);
            leftToRight = !leftToRight;
        }
        return result;
    }
}
```

## Explanation

### Problem Analysis

This is level order traversal with alternating direction: left-to-right for even levels, right-to-left for odd levels.

### Approach

Use BFS to process levels in order. For each level, either add to the end (`addLast`) or beginning (`addFirst`) of a `LinkedList` based on direction.

### Pattern Used

**BFS with bidirectional level insertion** using `LinkedList`.

### Key Insight

Rather than reversing lists or reordering afterward, insert each node in the correct position based on current direction using `LinkedList`'s `addFirst` and `addLast`.

### Code Walkthrough

1. Use BFS with direction flag `leftToRight`.
2. For each level, create a new `LinkedList`.
3. Process nodes: if `leftToRight`, use `addLast`; else `addFirst`.
4. Toggle direction after each level.
5. Return result.

### Example Walkthrough

For `[3,9,20,null,null,15,7]`:

- Level 0 (left-to-right): process 3 → add to end → `[3]`
- Level 1 (right-to-left): process 9, 20 → add 9 to start, 20 to start → `[20,9]`
- Level 2 (left-to-right): process 15, 7 → add to end → `[15,7]`

### Key Variables Explained

- **`leftToRight`**: direction flag for current level
- **`levelList`**: `LinkedList` allows efficient `addFirst` and `addLast`

### Why This Works

`LinkedList.addFirst` inserts at the beginning, and `addLast` at the end, efficiently creating the zigzag pattern in a single pass.

### Trick Used

Using `LinkedList` instead of `ArrayList`; `addFirst` is `O(1)` on `LinkedList` but would require shifting elements on `ArrayList`.

### Edge Cases Handled

1. Empty tree: returns empty list
2. Single node: returns `[[value]]`

### Complexity Analysis

- **Time Complexity: `O(n)`** — Each node processed once
- **Space Complexity: `O(w)`** — Queue size proportional to max width
