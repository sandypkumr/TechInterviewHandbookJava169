Given the `root` of a binary tree, _check whether it is a mirror of itself_ (i.e., symmetric around its center).

**Example 1:**

```
Input: root = [1,2,2,3,4,4,3]
Output: true
```

**Example 2:**

```
Input: root = [1,2,2,null,3,null,3]
Output: false
```

**Constraints:**

- The number of nodes in the tree is in the range `[1, 1000]`.

- `-100 <= Node.val <= 100`

**Follow up:** Could you solve it both recursively and iteratively?

**Patterns:** `sliding-window`

## Java Solution

```java
package binary_tree;

public class SymmetricTree {
    public boolean isSymmetric(TreeNode root) {
        return isMirror(root.left, root.right);
    }

    private boolean isMirror(TreeNode left, TreeNode right) {
        if (left == null && right == null) {
            return true;
        }
        if (left == null || right == null) {
            return false;
        }
        return left.val == right.val && isMirror(left.left, right.right) && isMirror(left.right, right.left);
    }
}
```

## Explanation

### Approach

**Symmetric Tree** asks about a contiguous subarray or substring, which is the classic signal for a sliding window. Instead of recomputing the window's property from scratch every time (O(n²)), we maintain a running state and slide one boundary at a time.

Think of it like looking through a physical window on a train — as the train moves you don't redraw the entire landscape; you simply note what enters on one side and what leaves on the other. The window expands when we want to include more elements and shrinks when a constraint is violated.

### Code Walkthrough

The solution is implemented in `isSymmetric(TreeNode root)`:

1. Initialise left and right pointers both at index 0.
2. Expand the window by advancing the right pointer and updating the window state.
3. When the window violates the constraint, shrink from the left until it is valid again.
4. At each valid state, update the global answer (max length, min size, etc.).
5. Continue until the right pointer reaches the end of the input.
