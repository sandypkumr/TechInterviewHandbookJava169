Given the `root` of a binary tree, return _the **maximum width** of the given tree_.

The **maximum width** of a tree is the maximum **width** among all levels.

The **width** of one level is defined as the length between the first and the last nodes of that level (null-only nodes between the leftmost and rightmost nodes are also counted into the length calculation).

**Example 1:**

```
Input: root = [1,3,2,5,3,null,9]
Output: 4
Explanation: The maximum width existing in the third level with the length 4 (5,3,null,9).
```

**Example 2:**

```
Input: root = [1,3,null,null,2]
Output: 2
```

**Example 3:**

```
Input: root = [1,3,2,5]
Output: 2
```

**Constraints:**

- The number of nodes in the tree is in the range `[1, 3000]`.

- `-100 <= Node.val <= 100`

## Java Solution

```java
package binary_tree;

import java.util.ArrayList;
import java.util.List;

public class MaximumWidthOfBinaryTree {
    private int maxWidth = 1;
    private final List<Integer> left = new ArrayList<>();

    public int widthOfBinaryTree(TreeNode root) {
        dfs(root, 0, 1);
        return maxWidth;
    }

    private void dfs(TreeNode node, int depth, int index) {
        if (node == null) {
            return;
        }
        if (depth == left.size()) {
            left.add(index);
        } else {
            maxWidth = Math.max(maxWidth, index - left.get(depth) + 1);
        }
        dfs(node.left, depth + 1, index * 2 - 1);
        dfs(node.right, depth + 1, index * 2);
    }
}
```

## Explanation

### Problem Analysis

Width of a level is the distance between the leftmost and rightmost nodes, including null nodes between them. Computing width naively would require tracking all nodes per level. The optimal approach uses index-based positioning: assign each node a position index assuming a complete binary tree layout.

### Approach

Use DFS with node indexing:
1. Assign index 1 to root
2. For any node at index i, left child is at index 2i-1, right child is at 2i
3. Track the leftmost node index for each depth
4. Width at depth d = (rightmost index) - (leftmost index) + 1
5. Since we visit left-to-right, first node at each depth is leftmost

### Pattern Used

**DFS with index-based positioning** for computing tree width.

### Key Insight

The key insight is that in a complete binary tree, node positions are determined by their path from root (left/right choices). By assigning indices, we can compute width as `rightmost - leftmost + 1` without explicitly storing all nodes.

### Code Walkthrough

```java
private int maxWidth = 1;  // Track maximum width
private final List<Integer> left = new ArrayList<>();  // Leftmost index for each depth

public int widthOfBinaryTree(TreeNode root) {
    dfs(root, 0, 1);  // Start: depth 0, index 1
    return maxWidth;
}
```

**DFS function:**
```java
private void dfs(TreeNode node, int depth, int index) {
    if (node == null) {
        return;  // Base case: null node
    }

    if (depth == left.size()) {
        // First time visiting this depth: this is the leftmost node
        left.add(index);
    } else {
        // Update maxWidth with current width at this depth
        maxWidth = Math.max(maxWidth, index - left.get(depth) + 1);
    }

    // Recurse with index doubling
    dfs(node.left, depth + 1, index * 2 - 1);   // Left child index
    dfs(node.right, depth + 1, index * 2);      // Right child index
}
```

1. **Base case**: Null node returns
2. **Record leftmost**: If first node at this depth, store its index
3. **Update width**: Compare current node's index with leftmost at this depth
4. **Index children**: Left child gets `index * 2 - 1`, right gets `index * 2`

### Example Walkthrough

For `root = [1,3,2,5,3,null,9]`:

```
         1 (index 1)
        / \
       3   2 (indices 1, 2)
      / \ / \
     5 3 ? 9 (indices 3,4,5,6 - positions in complete tree)
```

DFS execution:
- Depth 0: node 1, index 1. First at depth 0, left[0]=1. Recurse.
- Depth 1: node 3, index 1. First at depth 1, left[1]=1. Recurse.
- Depth 2: node 5, index 3. First at depth 2, left[2]=3. maxWidth = max(1, 3-3+1)=1. Recurse.
- Depth 2: node 3, index 4. maxWidth = max(1, 4-3+1)=2. Recurse.
- Depth 1: node 2, index 2. maxWidth = max(2, 2-1+1)=2. Recurse.
- Depth 2: node null (left). Return.
- Depth 2: node 9, index 6. maxWidth = max(2, 6-3+1)=4. Recurse.

Result: maxWidth = 4 ✓

### Key Variables Explained

- **`index`**: Position in a complete binary tree (1-based)
- **`depth`**: Level in the tree (0 is root)
- **`left`**: List storing leftmost node index at each depth
- **`left.get(depth)`**: Leftmost index at current depth
- **`index - left.get(depth) + 1`**: Width at current depth

### Why This Works

The algorithm is correct because:

1. **Index encoding**: Binary tree indexing is standard; left child = 2i-1, right child = 2i
2. **Leftmost is first**: DFS pre-order visits left subtree before right, so first node at each depth is leftmost
3. **Width formula**: Distance from leftmost to rightmost + 1 gives correct width
4. **Complete traversal**: All nodes are visited; maxWidth captures the global maximum

### Trick Used

The clever trick is the index assignment:

```java
dfs(node.left, depth + 1, index * 2 - 1);
dfs(node.right, depth + 1, index * 2);
```

This avoids storing all nodes at each level. Width is computed implicitly from indices, making the algorithm space-efficient.

### Edge Cases Handled

1. **Single node**: Returns 1
2. **Skewed tree**: Width=1 at all levels (only one node per level)
3. **Perfect binary tree**: Width increases at each level
4. **Unbalanced tree**: Correctly computes width based on actual positions

### Complexity Analysis

- **Time Complexity: `O(n)`** — Visit each node once
- **Space Complexity: `O(h)`** — Recursion depth plus left list (at most h entries)
