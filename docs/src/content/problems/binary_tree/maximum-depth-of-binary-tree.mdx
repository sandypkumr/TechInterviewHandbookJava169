Given the root of a binary tree, return its maximum depth.

A binary tree's **maximum depth** is the number of nodes along the longest path from the root node down to the farthest leaf node.

**Example 1:**

```
Input: root = [3,9,20,null,null,15,7]
Output: 3
```

**Example 2:**

```
Input: root = [1,null,2]
Output: 2
```

**Example 3:**

```
Input: root = []
Output: 0
```

**Constraints:**

- The number of nodes in the tree is in the range `[0, 10^4]`.

- `-100 <= Node.val <= 100`

## Java Solution

```java
package binary_tree;

public class MaximumDepthOfBinaryTree {
    public int maxDepth(TreeNode root) {
        if (root == null) {
            return 0;
        }
        return Math.max(maxDepth(root.left), maxDepth(root.right)) + 1;
    }
}
```

## Explanation

### Problem Analysis

Maximum depth is the count of nodes from root to the farthest leaf (inclusive).

### Approach

Recursively compute depth of left and right subtrees, return max + 1.

### Pattern Used

**Simple recursive DFS** with direct combination of subproblem results.

### Key Insight

Depth at any node = 1 + max(leftDepth, rightDepth). Base case: null has depth 0.

### Code Walkthrough

1. Base case: null returns 0
2. Recursively compute left depth
3. Recursively compute right depth
4. Return `max(leftDepth, rightDepth) + 1`

### Example Walkthrough

For `[3,9,20,null,null,15,7]`:

```
       3
      / \
     9   20
        /  \
       15   7
```

- Depth of 9 (leaf): 1
- Depth of 15 (leaf): 1
- Depth of 7 (leaf): 1
- Depth of 20: max(1, 1) + 1 = 2
- Depth of 3: max(1, 2) + 1 = 3

Result: 3

### Key Variables Explained

- **`left depth`/`right depth`**: depths of child subtrees

### Why This Works

Recursion directly computes the definition: max depth = 1 + max of children's depths.

### Trick Used

None; straightforward recursion.

### Edge Cases Handled

1. Empty tree: returns 0
2. Single node: returns 1

### Complexity Analysis

- **Time Complexity: `O(n)`** — Every node visited once
- **Space Complexity: `O(h)`** — Recursion stack depth
