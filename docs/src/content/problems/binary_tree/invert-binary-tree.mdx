Given the `root` of a binary tree, invert the tree, and return _its root_.

**Example 1:**

```
Input: root = [4,2,7,1,3,6,9]
Output: [4,7,2,9,6,3,1]
```

**Example 2:**

```
Input: root = [2,1,3]
Output: [2,3,1]
```

**Example 3:**

```
Input: root = []
Output: []
```

**Constraints:**

- The number of nodes in the tree is in the range `[0, 100]`.

- `-100 <= Node.val <= 100`

## Java Solution

```java
package binary_tree;

public class InvertBinaryTree {
    public TreeNode invertTree(TreeNode root) {
        if (root == null) {
            return null;
        }

        TreeNode temp = root.left;
        root.left = root.right;
        root.right = temp;

        invertTree(root.left);
        invertTree(root.right);

        return root;
    }
}
```

## Explanation

### Problem Analysis

Inverting a tree means swapping left and right children at every node.

### Approach

Recursive DFS: at each node, swap left and right children, then recurse on both.

### Pattern Used

**Simple recursive tree traversal** with in-place modification.

### Key Insight

Each node's inversion is independent: swap its children, then recurse.

### Code Walkthrough

1. Base case: null returns null
2. Swap left and right: `temp = left; left = right; right = temp`
3. Recursively invert left subtree
4. Recursively invert right subtree
5. Return root

### Example Walkthrough

For `[4,2,7,1,3,6,9]`:

Original:
```
       4
      / \
     2   7
    / \ / \
   1  3 6  9
```

- At node 4: swap children (2↔7), recurse
- At node 2: swap children (1↔3), recurse
- At node 1: null children, return
- At node 3: null children, return
- At node 7: swap children (6↔9), recurse
- At node 6: null children, return
- At node 9: null children, return

Result:
```
       4
      / \
     7   2
    / \ / \
   9  6 3  1
```

### Key Variables Explained

- **`temp`**: temporary storage for swapping

### Why This Works

Swapping children at every node inverts the tree. Recursion ensures every node is processed.

### Trick Used

None; straightforward swap using a temp variable.

### Edge Cases Handled

1. Empty tree: returns null
2. Single node: no children to swap

### Complexity Analysis

- **Time Complexity: `O(n)`** — Every node visited once
- **Space Complexity: `O(h)`** — Recursion stack depth
