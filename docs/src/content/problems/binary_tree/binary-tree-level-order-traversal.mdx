Given the `root` of a binary tree, return _the level order traversal of its nodes' values_. (i.e., from left to right, level by level).

**Example 1:**

```
Input: root = [3,9,20,null,null,15,7]
Output: [[3],[9,20],[15,7]]
```

**Example 2:**

```
Input: root = [1]
Output: [[1]]
```

**Example 3:**

```
Input: root = []
Output: []
```

**Constraints:**

- The number of nodes in the tree is in the range `[0, 2000]`.

- `-1000 <= Node.val <= 1000`

## Java Solution

```java
package binary_tree;

import java.util.ArrayList;
import java.util.LinkedList;
import java.util.List;
import java.util.Queue;

public class BinaryTreeLevelOrderTraversal {
    public List<List<Integer>> levelOrder(TreeNode root) {
        List<List<Integer>> result = new ArrayList<>();
        if (root == null) {
            return result;
        }
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);
        while (!queue.isEmpty()) {
            int levelSize = queue.size();
            List<Integer> level = new ArrayList<>();
            for (int i = 0; i < levelSize; i++) {
                TreeNode node = queue.poll();
                level.add(node.val);
                if (node.left != null) {
                    queue.offer(node.left);
                }
                if (node.right != null) {
                    queue.offer(node.right);
                }
            }
            result.add(level);
        }
        return result;
    }
}
```

## Explanation

### Problem Analysis

Level order traversal requires visiting nodes from top to bottom, left to right, one level at a time. Standard DFS explores depth-first; level order requires breadth-first exploration.

The key challenge is grouping nodes by level and returning them separately, not just returning all nodes in BFS order.

### Approach

Use BFS with a queue to explore nodes level by level. The crucial insight is capturing the queue size at the start of each iteration to know how many nodes belong to the current level.

### Pattern Used

This solution uses **breadth-first search (BFS) with level-based iteration**.

Unlike simple BFS that just traverses nodes, this solution explicitly groups nodes by their depth level.

### Key Insight

The key insight is that after adding all nodes from level `i` to the queue, the queue size equals the number of nodes at level `i+1`. By capturing `levelSize` before processing, we can handle exactly one level per while iteration.

### Code Walkthrough

1. Initialize result list and queue with root.

2. While queue is not empty:
   - Capture `levelSize = queue.size()` (number of nodes at current level)
   - Create a new list `level` for this level's values
   - Process exactly `levelSize` nodes (consuming one full level):
     - Poll each node, add its value to `level`
     - Offer its children to the queue for the next level
   - Add `level` to result

3. Return result containing all levels.

### Example Walkthrough

For `[3,9,20,null,null,15,7]`:

```
       3        (level 0)
      / \
     9   20     (level 1)
        /  \
       15   7  (level 2)
```

1. Queue: `[3]`, levelSize=1, process node 3, add 9 and 20
   - level = `[3]`, result = `[[3]]`
   - Queue: `[9, 20]`

2. Queue: `[9, 20]`, levelSize=2, process nodes 9 and 20
   - level = `[9, 20]`, result = `[[3], [9, 20]]`
   - Queue: `[15, 7]`

3. Queue: `[15, 7]`, levelSize=2, process nodes 15 and 7
   - level = `[15, 7]`, result = `[[3], [9, 20], [15, 7]]`
   - Queue: empty

4. Return `[[3], [9, 20], [15, 7]]`

### Key Variables Explained

- **`levelSize`**: number of nodes at current level; critical for one-level-per-iteration processing
- **`level`**: list of node values for current level
- **`queue`**: holds nodes to be processed; children are added as parents are polled

### Why This Works

BFS explores nodes in order of distance from root, naturally visiting all nodes at level `i` before any at level `i+1`. By capturing and processing exactly `levelSize` nodes per iteration, we group nodes by level.

### Trick Used

The main trick is capturing `levelSize` before the inner loop:

```java
int levelSize = queue.size();
for (int i = 0; i < levelSize; i++) {
    // Process exactly one level
}
```

This ensures we process all nodes added at the current level but not nodes added for future levels.

### Edge Cases Handled

1. **Empty tree**: Returns empty result.
2. **Single node**: Returns `[[rootValue]]`.
3. **Unbalanced tree**: Correctly groups nodes by level regardless of structure.

### Complexity Analysis

- **Time Complexity: `O(n)`** — Each node is visited exactly once.

- **Space Complexity: `O(w)`** — Queue size is proportional to the maximum tree width, where `w` is the maximum number of nodes at any level.
