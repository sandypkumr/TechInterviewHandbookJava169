Given the `root` of a binary tree, imagine yourself standing on the right side of it, return _the values of the nodes you can see ordered from top to bottom_.

**Example 1:**

```
Input: root = [1,2,3,null,5,null,4]
Output: [1,3,4]
```

**Example 2:**

```
Input: root = [1,null,3]
Output: [1,3]
```

**Example 3:**

```
Input: root = []
Output: []
```

**Constraints:**

- The number of nodes in the tree is in the range `[0, 100]`.

- `-100 <= Node.val <= 100`

## Java Solution

```java
package binary_tree;

import java.util.ArrayList;
import java.util.LinkedList;
import java.util.List;
import java.util.Queue;

public class BinaryTreeRightSideView {
    public List<Integer> rightSideView(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        if (root == null) {
            return result;
        }
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);
        while (!queue.isEmpty()) {
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();
                if (i == size - 1) {
                    result.add(node.val);
                }
                if (node.left != null) {
                    queue.offer(node.left);
                }
                if (node.right != null) {
                    queue.offer(node.right);
                }
            }
        }
        return result;
    }
}
```

## Explanation

### Problem Analysis

Standing on the right side of the tree, we see only the rightmost node at each level. The task is to collect these rightmost nodes in level order.

### Approach

Use BFS to traverse level by level. At each level, the last node processed (`i == size - 1`) is the rightmost node visible from the right side.

### Pattern Used

This solution uses **breadth-first search with last-node-per-level detection**.

### Key Insight

In BFS, all nodes at level `i` are processed before any at level `i+1`. The rightmost node is the last one at each level (index `size - 1` when processing in order).

### Code Walkthrough

1. Use BFS with a queue.
2. For each level, capture `size = queue.size()` (number of nodes at this level).
3. Process all `size` nodes, but only add the last one (`i == size - 1`) to result.
4. Continue until queue is empty.

### Example Walkthrough

For `[1,2,3,null,5,null,4]`:

```
       1           (level 0, rightmost: 1)
      / \
     2   3         (level 1, rightmost: 3)
      \   \
       5   4       (level 2, rightmost: 4)
```

**BFS levels:**
- Level 0: [1] → rightmost is index 0 → add 1
- Level 1: [2, 3] → rightmost is index 1 (3) → add 3
- Level 2: [5, 4] → rightmost is index 1 (4) → add 4

**Result: [1, 3, 4]**

### Key Variables Explained

- **`size`**: number of nodes at current level
- **`i`**: index of node within level
- **`i == size - 1`**: condition for rightmost node

### Why This Works

BFS guarantees level-by-level processing. The rightmost node at each level is processed last and has index `size - 1`.

### Trick Used

Simple index comparison: `i == size - 1` identifies the last node at each level in a single pass.

### Edge Cases Handled

1. **Empty tree**: Returns empty list.
2. **Single node**: Returns that node.
3. **Right-skewed tree**: Returns all nodes (each is rightmost at its level).
4. **Left-skewed tree**: Returns only the leftmost path (visible from right).

### Complexity Analysis

- **Time Complexity: `O(n)`** — All nodes visited once.

- **Space Complexity: `O(w)`** — Queue size proportional to max tree width.
