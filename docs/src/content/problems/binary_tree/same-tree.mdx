Given the roots of two binary trees `p` and `q`, write a function to check if they are the same or not.

Two binary trees are considered the same if they are structurally identical, and the nodes have the same value.

**Example 1:**

```
Input: p = [1,2,3], q = [1,2,3]
Output: true
```

**Example 2:**

```
Input: p = [1,2], q = [1,null,2]
Output: false
```

**Example 3:**

```
Input: p = [1,2,1], q = [1,1,2]
Output: false
```

**Constraints:**

- The number of nodes in both trees is in the range `[0, 100]`.

- `-10^4 <= Node.val <= 10^4`

## Java Solution

```java
package binary_tree;

public class SameTree {
    public boolean isSameTree(TreeNode p, TreeNode q) {
        if (p == null && q == null) {
            return true;
        }
        if (p == null || q == null) {
            return false;
        }
        return p.val == q.val && isSameTree(p.left, q.left) && isSameTree(p.right, q.right);
    }
}
```

## Explanation

### Problem Analysis
We need to determine whether two binary trees are identical in both structure and node values. Matching values alone are not enough; the left and right child layout must also match exactly.

This is a standard interview problem because it tests recursive tree comparison. The main skill is recognizing that two trees are the same only if their roots match and their corresponding subtrees also match.

### Approach
The code compares the two trees node-by-node using recursive DFS. At each step, it handles the null cases first, then checks whether the current values match, and finally compares the left subtrees and right subtrees.

This is better than trying to serialize both trees first or collecting traversals into arrays. Direct recursive comparison is simpler and stops early as soon as a mismatch is found.

### Pattern Used
DFS recursion on two trees simultaneously.

### Key Insight
Two trees are the same if and only if the current pair of nodes match and both corresponding child pairs also match.

### Code Walkthrough
The method is `isSameTree(TreeNode p, TreeNode q)`.

- `if (p == null && q == null) { return true; }`
  - If both nodes are missing, the trees match at this position.

- `if (p == null || q == null) { return false; }`
  - If only one node exists, the structures differ immediately.

- `return p.val == q.val && isSameTree(p.left, q.left) && isSameTree(p.right, q.right);`
  - First compare the current values.
  - Then recursively compare the left children.
  - Then recursively compare the right children.
  - Because `&&` short-circuits, the method stops early once any check becomes false.

There is no extra storage because the recursion itself expresses the comparison.

### Example Walkthrough
Use Example 1: `p = [1,2,3]`, `q = [1,2,3]`.

- Compare roots `1` and `1`.
  - values match, so continue.

- Compare left children `2` and `2`.
  - values match.
  - their left children are both `null`, so return `true`.
  - their right children are both `null`, so return `true`.
  - subtree at value `2` matches.

- Compare right children `3` and `3`.
  - values match.
  - both left children are `null`.
  - both right children are `null`.
  - subtree at value `3` matches.

Since root values, left subtrees, and right subtrees all match, the final answer is `true`.

For Example 2, the method returns `false` when one side has a node where the other side has `null`, which correctly detects the structural mismatch.

### Key Variables Explained
- `p`: current node from the first tree.
- `q`: current node from the second tree.
- `p.val == q.val`: value comparison at the current position.
- `isSameTree(p.left, q.left)`: verifies left-subtree equality.
- `isSameTree(p.right, q.right)`: verifies right-subtree equality.

### Why This Works
The method enforces the exact definition of identical trees. A pair of subtrees can only be equal when:

- both roots are absent, or
- both roots are present, have the same value, and their left and right subtrees are also equal

Those are precisely the cases the code checks. Because every corresponding node pair is compared once, and any mismatch returns `false` immediately, the algorithm is both correct and efficient.

### Trick Used
No specific trick — the solution is direct and straightforward

### Edge Cases Handled
- Both trees empty: the first `if` returns `true`.
- One tree empty and the other non-empty: the second `if` returns `false`.
- Same values but different structure: recursive null checks detect the mismatch.
- Same structure but different values: `p.val == q.val` fails.

### Complexity Analysis
- **Time Complexity: `O(n)`**
  - Each corresponding node pair is compared once.
  - In the worst case, all nodes must be checked.

- **Space Complexity: `O(h)`**
  - Extra space comes only from the recursion stack.
  - `h` is the height of the trees.
