Given the roots of two binary trees `p` and `q`, write a function to check if they are the same or not.

Two binary trees are considered the same if they are structurally identical, and the nodes have the same value.

**Example 1:**

```
Input: p = [1,2,3], q = [1,2,3]
Output: true
```

**Example 2:**

```
Input: p = [1,2], q = [1,null,2]
Output: false
```

**Example 3:**

```
Input: p = [1,2,1], q = [1,1,2]
Output: false
```

**Constraints:**

- The number of nodes in both trees is in the range `[0, 100]`.

- `-10^4 <= Node.val <= 10^4`

## Java Solution

```java
package binary_tree;

public class SameTree {
    public boolean isSameTree(TreeNode p, TreeNode q) {
        if (p == null && q == null) {
            return true;
        }
        if (p == null || q == null) {
            return false;
        }
        return p.val == q.val && isSameTree(p.left, q.left) && isSameTree(p.right, q.right);
    }
}
```

## Explanation

### Approach

**Same Tree** needs to explore all possible paths or the full extent of a connected region — the classic use-case for Depth-First Search (DFS). DFS dives as deep as possible along one branch before backtracking, making it ideal for connectivity, cycle detection, and exhaustive enumeration.

Imagine navigating a maze by always turning left until you hit a dead end, then backtracking to the last junction and trying the next option. DFS systematically explores every possibility without re-visiting the same cell.

### Code Walkthrough

The solution is implemented in `isSameTree(TreeNode p, TreeNode q)`:

1. Choose a starting node and mark it as visited.
2. Recursively (or with an explicit stack) visit each unvisited neighbour.
3. Perform the required computation during entry or exit of each node.
4. Backtrack naturally when recursion returns — the call stack handles the state.
5. Repeat for all unvisited nodes to cover disconnected components if needed.

### Complexity Analysis

- **Time Complexity: `O(n)`** — the input is processed in a single linear pass.
- **Space Complexity: `O(h)`** — auxiliary space proportional to the input is required.
