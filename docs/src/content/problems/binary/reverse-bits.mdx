Reverse bits of a given 32 bits signed integer.

**Example 1:**

**Input:** n = 43261596

**Output:** 964176192

**Explanation:**

**Example 2:**

**Input:** n = 2147483644

**Output:** 1073741822

**Explanation:**

**Constraints:**

- `0 <= n <= 2^31 - 2`

- `n` is even.

**Follow up:** If this function is called many times, how would you optimize it?

## Java Solution

```java
package binary;

public class ReverseBits {
    public int reverseBits(int n) {
        int result = 0;
        for (int i = 0; i < 32; i++) {
            result <<= 1;
            result |= (n & 1);
            n >>= 1;
        }
        return result;
    }
}
```
