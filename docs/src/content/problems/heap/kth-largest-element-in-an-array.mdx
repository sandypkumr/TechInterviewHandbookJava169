Given an integer array `nums` and an integer `k`, return _the_ `k^th` _largest element in the array_.

Note that it is the `k^th` largest element in the sorted order, not the `k^th` distinct element.

Can you solve it without sorting?

**Example 1:**

```
Input: nums = [3,2,1,5,6,4], k = 2
Output: 5
```
**Example 2:**

```
Input: nums = [3,2,3,1,2,4,5,5,6], k = 4
Output: 4
```

**Constraints:**

- `1 <= k <= nums.length <= 10^5`

- `-10^4 <= nums[i] <= 10^4`

**Patterns:** `heap`

## Java Solution

```java
package heap;

import java.util.PriorityQueue;

public class KthLargestElementInAnArray {
    public int findKthLargest(int[] nums, int k) {
        PriorityQueue<Integer> minHeap = new PriorityQueue<>();

        for (int num : nums) {
            minHeap.offer(num);
            if (minHeap.size() > k) {
                minHeap.poll();
            }
        }

        return minHeap.peek();
    }
}
```

## Explanation

### Approach

**Kth Largest Element in an Array** needs to repeatedly find the smallest or largest element from a dynamically changing collection. A heap (Java's `PriorityQueue`) maintains this invariant with O(log n) insert and O(log n) remove, far better than sorting the entire collection each time.

A min-heap is like a waiting room where the most urgent patient always sits at the front. As patients arrive or leave, the room reorganises in O(log n) time to keep the most urgent at the front — you never need to scan everyone to find them.

### Code Walkthrough

The solution is implemented in `findKthLargest(int[] nums, int k)`:

1. Choose a min-heap (natural order) or max-heap (Comparator.reverseOrder()).
2. Insert elements as you process them.
3. Poll the top element when you need the current minimum/maximum.
4. For "top-K" problems, keep the heap size bounded at K to save memory.
5. After processing, the remaining heap elements or the polled sequence is your answer.

### Complexity Analysis

- **Time Complexity: `O(n log k)`** — see the analysis for full details.
- **Space Complexity: `O(k)`** — auxiliary space proportional to the input is required.
