Given two strings `s` and `t` of lengths `m` and `n` respectively, return _the **minimum window**_ **_substring_**_ of _`s`_ such that every character in _`t`_ (**including duplicates**) is included in the window_. If there is no such substring, return _the empty string _`""`.

The testcases will be generated such that the answer is **unique**.

**Example 1:**

```
Input: s = "ADOBECODEBANC", t = "ABC"
Output: "BANC"
Explanation: The minimum window substring "BANC" includes 'A', 'B', and 'C' from string t.
```

**Example 2:**

```
Input: s = "a", t = "a"
Output: "a"
Explanation: The entire string s is the minimum window.
```

**Example 3:**

```
Input: s = "a", t = "aa"
Output: ""
Explanation: Both 'a's from t must be included in the window.
Since the largest window of s only has one 'a', return empty string.
```

**Constraints:**

- `m == s.length`

- `n == t.length`

- `1 <= m, n <= 10^5`

- `s` and `t` consist of uppercase and lowercase English letters.

**Follow up:** Could you find an algorithm that runs in `O(m + n)` time?

**Patterns:** `sliding-window`

## Java Solution

```java
package string;

public class MinimumWindowSubstring {
    public String minWindow(String s, String t) {
        if (s.length() < t.length()) return "";

        int[] tCount = new int[128];
        for (char c : t.toCharArray()) {
            tCount[c]++;
        }

        int left = 0, right = 0, minLen = Integer.MAX_VALUE, minLeft = 0;
        int required = t.length();
        int[] sCount = new int[128];

        while (right < s.length()) {
            char cRight = s.charAt(right);
            sCount[cRight]++;
            if (sCount[cRight] <= tCount[cRight]) {
                required--;
            }

            while (required == 0) {
                if (right - left + 1 < minLen) {
                    minLen = right - left + 1;
                    minLeft = left;
                }

                char cLeft = s.charAt(left);
                sCount[cLeft]--;
                if (sCount[cLeft] < tCount[cLeft]) {
                    required++;
                }
                left++;
            }
            right++;
        }

        return minLen == Integer.MAX_VALUE ? "" : s.substring(minLeft, minLeft + minLen);
    }
}
```

## Explanation

### Approach

**Minimum Window Substring** asks about a contiguous subarray or substring, which is the classic signal for a sliding window. Instead of recomputing the window's property from scratch every time (O(n²)), we maintain a running state and slide one boundary at a time.

Think of it like looking through a physical window on a train — as the train moves you don't redraw the entire landscape; you simply note what enters on one side and what leaves on the other. The window expands when we want to include more elements and shrinks when a constraint is violated.

### Code Walkthrough

The solution is implemented in `minWindow(String s, String t)`:

1. Initialise left and right pointers both at index 0.
2. Expand the window by advancing the right pointer and updating the window state.
3. When the window violates the constraint, shrink from the left until it is valid again.
4. At each valid state, update the global answer (max length, min size, etc.).
5. Continue until the right pointer reaches the end of the input.

> **Note:** This solution also uses the **HashMap for O(1) average-case lookups** technique.

### Complexity Analysis

- **Time Complexity: `O(n)`** — the array is traversed exactly once; all HashMap/HashSet operations are O(1) amortised.
- **Space Complexity: `O(1)`** — only a fixed number of extra variables are used; no data structures that scale with input.
