You are given a string `s` and an integer `k`. You can choose any character of the string and change it to any other uppercase English character. You can perform this operation at most `k` times.

Return _the length of the longest substring containing the same letter you can get after performing the above operations_.

**Example 1:**

```
Input: s = "ABAB", k = 2
Output: 4
Explanation: Replace the two 'A's with two 'B's or vice versa.
```

**Example 2:**

```
Input: s = "AABABBA", k = 1
Output: 4
Explanation: Replace the one 'A' in the middle with 'B' and form "AABBBBA".
The substring "BBBB" has the longest repeating letters, which is 4.
There may exists other ways to achieve this answer too.
```

**Constraints:**

- `1 <= s.length <= 10^5`

- `s` consists of only uppercase English letters.

- `0 <= k <= s.length`

**Patterns:** `sliding-window`

## Java Solution

```java
package string;

public class LongestRepeatingCharacterReplacement {
    public int characterReplacement(String s, int k) {
        int[] count = new int[26];
        int maxCount = 0;
        int left = 0;
        int maxLength = 0;

        for (int right = 0; right < s.length(); right++) {
            count[s.charAt(right) - 'A']++;
            maxCount = Math.max(maxCount, count[s.charAt(right) - 'A']);

            while (right - left + 1 - maxCount > k) {
                count[s.charAt(left) - 'A']--;
                left++;
            }

            maxLength = Math.max(maxLength, right - left + 1);
        }

        return maxLength;
    }
}
```

## Explanation

### Problem Analysis
We need the length of the longest substring that can be turned into all one repeated character after at most `k` replacements.
This is a classic interview problem because it looks combinational at first, but the correct solution comes from maintaining a valid window instead of trying every substring.

### Approach
The code uses a sliding window `[left, right]` and tracks how many times each uppercase letter appears inside that window.
A window is usable if all characters except the most frequent one can be replaced within `k` operations. That means the number of required replacements is `window length - maxCount`, so we expand with `right` and shrink with `left` only when that value becomes too large.

### Pattern Used
Sliding Window

### Key Insight
A window is valid whenever its size minus the frequency of its most common character is at most `k`, because those are exactly the characters we would replace.

### Code Walkthrough
The method `characterReplacement(String s, int k)` starts with:
- `int[] count = new int[26];`
- `int maxCount = 0;`
- `int left = 0;`
- `int maxLength = 0;`

The loop `for (int right = 0; right < s.length(); right++)` expands the window one character at a time.
- `count[s.charAt(right) - 'A']++` updates the frequency of the newly included character.
- `maxCount = Math.max(maxCount, count[s.charAt(right) - 'A'])` stores the highest single-character frequency seen in the current expansion history.

Then the code checks whether the window needs too many replacements:
- `while (right - left + 1 - maxCount > k)`

If that condition is true, the window is invalid.
- `count[s.charAt(left) - 'A']--` removes the leftmost character from the frequency table.
- `left++` shrinks the window until it becomes valid again.

After the window is valid, the code updates:
- `maxLength = Math.max(maxLength, right - left + 1);`

At the end, `maxLength` is returned.

### Example Walkthrough
Use Example 2: `s = "AABABBA"`, `k = 1`.

Start with `left = 0`, `maxCount = 0`, `maxLength = 0`.

`right = 0`, char = `'A'`
- `count['A'] = 1`, `maxCount = 1`
- Window = `"A"`, replacements needed = `1 - 1 = 0`
- `maxLength = 1`

`right = 1`, char = `'A'`
- `count['A'] = 2`, `maxCount = 2`
- Window = `"AA"`, replacements needed = `2 - 2 = 0`
- `maxLength = 2`

`right = 2`, char = `'B'`
- Window = `"AAB"`
- `maxCount = 2`, replacements needed = `3 - 2 = 1`
- Valid, so `maxLength = 3`

`right = 3`, char = `'A'`
- Window = `"AABA"`
- `count['A'] = 3`, `maxCount = 3`
- Replacements needed = `4 - 3 = 1`
- Valid, so `maxLength = 4`

`right = 4`, char = `'B'`
- Window = `"AABAB"`
- Replacements needed = `5 - 3 = 2`, too many
- Shrink once: remove `s[left] = 'A'`, then `left = 1`
- Window becomes valid again

The algorithm keeps sliding and never finds a valid window longer than `4`, so it returns `4`.

### Key Variables Explained
- `count`: frequency array for letters `'A'` to `'Z'` inside the current window
- `left`: left boundary of the sliding window
- `right`: right boundary added by the outer loop
- `maxCount`: highest frequency of any single character seen for the window logic
- `maxLength`: best valid window length found so far

### Why This Works
For any window, the cheapest way to make all characters equal is to keep the majority character and replace everything else.
So the minimum replacements needed is exactly `window length - most frequent character count`. The code enforces that invariant with `while (right - left + 1 - maxCount > k)`. Once the condition is false, the current window can be converted into a repeated-character substring, so it is safe to use it to update `maxLength`.

### Trick Used
The optimization is keeping `maxCount` as a running maximum instead of recomputing the true maximum frequency every time the window shrinks.

### Edge Cases Handled
- `k = 0`: the while condition still works and only allows windows that already contain one repeated character
- Entire string already valid: the window keeps expanding and returns `s.length()`
- Frequent shrinking near the boundary: `left` moves only forward, so no index is revisited unnecessarily
- Single-character string: one loop iteration makes `maxLength = 1`

### Complexity Analysis
- Time Complexity: `O(n)`
  - `right` moves from left to right once
  - `left` also moves from left to right at most once overall
- Space Complexity: `O(1)`
  - `count` has fixed size 26 regardless of input length
