Write a function to find the longest common prefix string amongst an array of strings.

If there is no common prefix, return an empty string `""`.

**Example 1:**

```
Input: strs = ["flower","flow","flight"]
Output: "fl"
```

**Example 2:**

```
Input: strs = ["dog","racecar","car"]
Output: ""
Explanation: There is no common prefix among the input strings.
```

**Constraints:**

- `1 <= strs.length <= 200`

- `0 <= strs[i].length <= 200`

- `strs[i]` consists of only lowercase English letters if it is non-empty.

**Patterns:** `prefix-sum`

## Java Solution

```java
package string;

public class LongestCommonPrefix {
    public String longestCommonPrefix(String[] strs) {
        String prefix = strs[0];

        for (int i = 1; i < strs.length; i++) {
            while (strs[i].indexOf(prefix) != 0) {
                prefix = prefix.substring(0, prefix.length() - 1);
                if (prefix.isEmpty()) {
                    return "";
                }
            }
        }

        return prefix;
    }
}
```

## Explanation

### Problem Analysis
We need the longest prefix shared by every string in the array.
The answer can only get shorter as we compare more strings, so the main task is to keep trimming a candidate prefix until every string agrees with it.
This is a popular interview question because it looks simple but rewards careful boundary handling and efficient prefix checking.

### Approach
The code starts with the entire first string as the current candidate prefix.
Then it compares that candidate against each later string.
If the current string does not start with `prefix`, the code removes the last character from `prefix` and tries again.
That continues until the current string starts with `prefix` or `prefix` becomes empty.
This is better than checking every possible prefix from scratch for every string.

### Pattern Used
This solution primarily relies on direct iteration with progressive prefix reduction.

### Key Insight
The common prefix never grows; it can only stay the same or shrink as more strings are processed.

### Code Walkthrough
The method begins with `String prefix = strs[0]`.
That treats the first string as the longest possible starting candidate.

The outer loop `for (int i = 1; i < strs.length; i++)` compares this candidate against every remaining string.
For each `strs[i]`, the inner loop checks `while (strs[i].indexOf(prefix) != 0)`.
That condition means the current string does not start with `prefix`.

When the prefix does not match the start of `strs[i]`, the code shrinks it using:
- `prefix = prefix.substring(0, prefix.length() - 1)`

After shrinking, it checks `if (prefix.isEmpty())`.
- If true, there is no common prefix at all, so it returns `""` immediately.

If the `while` loop ends, then `strs[i]` starts with the current `prefix`, so the algorithm moves on to the next string.
After all strings are processed, `return prefix` gives the longest common prefix shared by the full array.

### Example Walkthrough
Use Example 1: `strs = ["flower","flow","flight"]`.
- Start with `prefix = "flower"`.
- Compare with `"flow"`:
  - `"flow".indexOf("flower") != 0`, so shrink to `"flowe"`.
  - Still not at index `0`, shrink to `"flow"`.
  - Now `"flow".indexOf("flow") == 0`, so stop shrinking.
- Compare with `"flight"`:
  - `"flight".indexOf("flow") != 0`, shrink to `"flo"`.
  - Still no match, shrink to `"fl"`.
  - `"flight".indexOf("fl") == 0`, so stop.

All strings share `"fl"`, so the method returns `"fl"`.

### Key Variables Explained
- `prefix`: current best candidate for the common prefix across all strings processed so far.
- `i`: index of the string currently being compared against `prefix`.
- `strs[i]`: the current string that may force `prefix` to shrink.

### Why This Works
After processing each index `i`, `prefix` is guaranteed to be a prefix of every string from `strs[0]` through `strs[i]`.
If `strs[i]` does not start with the current `prefix`, removing the last character is safe because any valid common prefix must be shorter.
The loop keeps shrinking until the invariant is restored.
When the algorithm finishes, no longer prefix could work for all strings, so the remaining `prefix` is the longest common prefix.

### Trick Used
The trick is progressive prefix shrinking: instead of building candidate prefixes upward, the code starts with the maximum possible prefix and trims only when necessary.

### Edge Cases Handled
- No common prefix, such as `["dog","racecar","car"]`: `prefix` shrinks to empty and returns `""`.
- Single string array: the outer loop never runs, so the first string is returned.
- One string shorter than the first: repeated shrinking adjusts `prefix` down to the valid shared portion.
- Empty string in the array: the `while` loop shrinks `prefix` to empty and returns `""`.

### Complexity Analysis
- **Time Complexity: `O(n · m^2)` in the worst case** — for each of the `n - 1` remaining strings, the code may shrink `prefix` one character at a time, and each `indexOf(prefix)` plus `substring(...)` operation can cost up to `O(m)`, where `m` is the length of the first string.
- **Space Complexity: `O(m)`** — the algorithm stores the current `prefix`, and shrinking via `substring` creates new prefix strings whose maximum length is at most `m`.
